# Release 4.15.8 (November 9, 2023)

## Overview
This release introduces buffer file compression to improve I/O performance, particularly for network drive operations.

## Changes
- **Performance**: Added GZIP compression for buffer files
- **I/O Optimization**: Enhanced network drive performance
- **File Processing**: Updated parquet serialization for compressed files

## Technical Details
- **Compression Implementation**:
  - Added GZIP compression for buffer file storage
  - Implemented compression at write time using flate2 encoder
  - Added decompression support in parquet serialization
  - Optimized compression settings for performance

- **I/O Improvements**:
  - Reduced network I/O overhead through compression
  - Enhanced buffer write performance
  - Improved file transfer efficiency
  - Optimized storage space usage

- **File Processing Updates**:
  - Added compressed file reading support in parquet serialization
  - Implemented streaming decompression for parquet conversion
  - Enhanced error handling for compressed file operations
  - Updated file handling logic to support compressed formats
