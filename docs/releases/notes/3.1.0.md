# Version 3.1.0 Release Notes

## Error Handling and Reliability Improvements
- Implemented less aggressive backoff strategy for retries
- Enhanced retry/backoff mechanism for better error recovery
- Added handling for non-existent S3 objects in inventory
- Improved handling of objects recorded in inventory that may no longer exist
- Fixed support for integer field names in data processing

## Date and Time Handling
- Added support for additional ISO8601 date time formats
- Fixed date field parsing to support all known formats
- Optimized date cardinality by bucketing by year
- Enhanced timestamp handling in various operations

## CI/CD and Testing Enhancements
- Implemented staggered E2E tests to prevent Athena database creation conflicts
- Added chaos mode testing for S3 and inventory plugins
- Enhanced test coverage with additional test cases
- Improved cleanup procedures in CI/CD pipeline
- Added Docker build caching for faster builds

## Performance Optimizations
- Removed verbose logging for better performance
- Optimized partition field handling
- Improved S3 prefix cleaning
- Enhanced map ingestion efficiency
- Fixed partition path handling for better organization

## Technical Details
- Improved Ctrl+C handling for better process management
- Enhanced schema synchronization and metadata handling
- Fixed support for empty field name edge cases
- Optimized Docker build process with improved caching
- Added comprehensive E2E test suite for various features:
  - S3 plugin operations
  - Inventory management
  - Event type handling
  - Time bucket processing
  - Chaos mode testing
