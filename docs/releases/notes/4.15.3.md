# Release 4.15.3 (November 2, 2023)

## Overview
This release introduces the ability to reset offsets and buffer files for pipelines, providing better control over data ingestion and processing.

## Changes
- **Pipeline Management**: Added support for resetting offsets and buffer files
- **Configuration**: Enhanced pipeline configuration with reset_offsets option
- **Environment Cache**: Added functionality to reset environment cache
- **Error Handling**: Improved error logging in AWS S3 operations

## Technical Details
- **Offset Reset Feature**:
  - Added new `reset_offsets` configuration option in pipeline settings
  - Implemented functionality to purge buffer files and reset offsets for specific pipelines
  - Added clear user feedback when reset operations are performed
  - Environment variable support through `RESET_OFFSETS` with default value of "false"

- **Configuration Enhancements**:
  - Added `reset_offsets` field to Pipeline configuration structure
  - Implemented `get_reset_offset()` method for checking reset status
  - Enhanced pipeline configuration initialization with reset options
  - Added support for resetting individual pipelines or all pipelines

- **Environment Cache Management**:
  - Added `reset_envcache()` method to clear environment variable cache
  - Improved cache handling during multi-pipeline operations
  - Enhanced environment variable management for pipeline-specific settings

- **Error Handling Improvements**:
  - Streamlined S3 upload error reporting
  - Enhanced error messages for failed operations
  - Added descriptive feedback for reset operations
  - Improved logging of pipeline status changes
