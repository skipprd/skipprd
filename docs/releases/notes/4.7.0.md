# Release 4.7.0

Release Date: July 22, 2023

## Changes

### Architecture Improvements
- Separated schema and data output plugins:
  - Added dedicated schema output plugin configuration
  - Improved AWS Glue schema management
  - Enhanced plugin isolation and flexibility

### Buffer Management
- Reorganized buffer directory structure:
  - Renamed and standardized buffer directories
  - Added dedicated deadletter buffer directory
  - Improved file path handling and organization
  - Enhanced buffer file management

### Performance Improvements
- Enhanced file handling:
  - Improved buffer file rotation
  - Optimized file writing operations
  - Better error handling for file operations

### Testing
- Improved E2E testing:
  - Increased batch size for very small file tests
  - Enhanced test reliability
  - Better resource utilization in tests
