# Release Notes for Version 4.4.11

## Overview
This release focuses on improving error handling in the S3 inventory plugin and enhancing CI/CD pipeline configuration for data quality testing.

## Key Changes

### Error Handling Improvements
- Modified error message display in S3 inventory plugin
- Removed detailed error string from retry messages
- Improved readability of retry notifications

### CI/CD Pipeline Enhancements
- Re-enabled Soda data quality testing in the pipeline
- Uncommented after_script sections for data quality checks
- Added data quality validation for both regular and chaos mode S3 inventory tests

### Technical Details
- Updated retry message format in S3 inventory plugin:
  - Now shows only object key and backoff duration
  - Removed potentially sensitive error details from logs
- Enhanced pipeline configuration:
  - Added Soda data quality checks for inventory_s3_plugin
  - Added Soda data quality checks for chaos_mode_inventory_s3
  - Maintained consistent environment variable configuration

## Developer Notes
The primary focus of this release was to improve error handling visibility and re-enable data quality testing in the CI/CD pipeline. The changes provide better operational clarity while ensuring data quality through automated testing.
