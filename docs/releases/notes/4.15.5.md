# Release 4.15.5 (November 7, 2023)

## Overview
This release enhances schema handling, improves file I/O performance, and reintroduces advanced type system features.

## Changes
- **Schema Management**: Fixed schema command functionality
- **File I/O**: Optimized buffer writing operations
- **Type System**: Reintroduced map support and array of records
- **Error Handling**: Improved S3 input error logging

## Technical Details
- **Schema Improvements**:
  - Updated schema command to use pipeline configuration
  - Enhanced schema initialization process
  - Fixed schema command parameter handling
  - Improved schema discovery and validation

- **File I/O Optimizations**:
  - Removed redundant buffering in file writes
  - Implemented direct file synchronization
  - Enhanced buffer rotation mechanism
  - Improved file system operation efficiency

- **Type System Enhancements**:
  - Reintroduced support for map data types
  - Added array of records functionality
  - Enhanced type inference for complex structures
  - Improved type validation and testing

- **Error Handling Updates**:
  - Enhanced S3 error message formatting
  - Improved error reporting in file operations
  - Added detailed error context for S3 operations
  - Enhanced error handling in buffer management
