# Version 4.17.33

## Changes

### Performance Optimization
- Major performance improvement for handling common JSON newline patterns
- Implemented fast-path processing for well-formed JSON lines
- Optimized JSON parsing with early validation and processing
- Reduced processing overhead for standard JSON formats

### Error Handling
- Enhanced JSON parsing error handling with more targeted error recovery
- Improved handling of malformed JSON lines
- Added targeted cleanup for problematic JSON only when needed
- Implemented more efficient string cleaning for error cases

### Code Structure
- Reorganized JSON parsing logic for better performance
- Separated standard JSON processing from error recovery paths
- Improved code organization in the JSON parser
- Added optimized line-by-line processing

## Technical Details
- Modified `src/serdes/json.rs` to implement optimized JSON parsing
- Added fast-path JSON line validation and processing
- Implemented targeted error recovery for problematic JSON formats
- Improved handling of newline-delimited JSON with better performance
- Enhanced regex-based cleanup to apply only to lines that need it

## Impact
This release significantly improves performance when processing common JSON formats with optimized newline handling. By implementing a fast-path for standard JSON lines and only applying extensive cleanup to problematic lines, the system can process data more efficiently. This change reduces CPU utilization and improves throughput, especially for large datasets with well-formed JSON records. The targeted error handling ensures that even when some JSON lines are malformed, the system can still process the remaining data efficiently.
