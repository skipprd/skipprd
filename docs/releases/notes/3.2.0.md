# Version 3.2.0 Release Notes

## Configuration Improvements
- Renamed environment variables for better clarity and organization:
  - `DATA_SOURCE_FLATTEN_EVENTS` → `TRANSFORM_FLATTEN_EVENTS`
  - `DATA_OUTPUT_TIME_BUCKET` → `TRANSFORM_BATCH_TIME_UNIT`
  - `DATA_OUTPUT_TIME_FIELDS` → `TRANSFORM_BATCH_TIME_FIELDS`
  - `DATA_OUTPUT_PARTITION_BY_FIELDS` → `TRANSFORM_BATCH_PARTITION_FIELDS`
  - `DATA_SOURCE_EVENT_TYPE_FIELDS` → `TRANSFORM_NAMESPACE_FIELDS`
  - `S3_BUCKET` → `DATA_SOURCE_S3_BUCKET`
  - `S3_PREFIX` → `DATA_SOURCE_S3_PREFIX`
  - `GLUE_DATABASE_NAME` → `SCHEMA_OUTPUT_GLUE_DATABASE_NAME`
  - `ATHENA_WORKGROUP_NAME` → `DATA_OUTPUT_ATHENA_WORKGROUP_NAME`

## Field Handling Enhancements
- Added workaround and debugging support for handling blank fields
- Improved validation of environment variable dependencies
- Enhanced error messaging for missing required configuration pairs

## Technical Details
- Updated CI/CD configuration to use new environment variable names
- Maintained backward compatibility with existing functionality
- Updated test cases to reflect new configuration naming
- Enhanced error handling for configuration validation
- Improved namespace handling and field name cleaning logic
