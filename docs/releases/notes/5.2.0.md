# Version 5.2.0

## Changes
- Implemented asynchronous streaming of Parquet data to object store
- Added shared output plugin instance across threads
- Fixed empty array fields when flattening records
- Added polymorphic output plugins
- Enhanced metrics tracking for WAL and Parquet operations

## Technical Details

### Performance Improvements
- Reduced disk I/O by streaming Parquet data directly to object store
- Implemented object store persistence in ingestion threads for better back pressure control
- Added multi-threaded uploads instead of single flushing thread
- Enhanced asynchronous operations for Parquet persistence
- Optimized buffer management to prevent large WAL file buildup

### Plugin Architecture Enhancements
- Implemented polymorphic output plugins for greater flexibility
- Added shared output plugin instance across threads for better resource utilization
- Improved local file output plugin with partition directory creation
- Enhanced plugin initialization and lifecycle management
- Added randomized output file names to prevent clobbering existing partition files

### Metrics Enhancements
- Added wal_compacted_bytes_total/current metrics for tracking data durably written
- Added wal_compacted_rows_total/current metrics for WAL row tracking
- Added wal_compacted_files_total/current metrics for WAL file count
- Added parquet_persisted_bytes_total/current metrics for object store tracking
- Added parquet_persisted_rows_total/current metrics for persisted row counts
- Added parquet_persisted_objects_total/current metrics for object count
- Added latest_timestamp metric for tracking most recent data timestamp

### Bug Fixes
- Fixed issue with empty array fields when flattening records
- Enhanced error handling for data transformations
- Improved logging for better troubleshooting
- Fixed partition handling in output plugins
