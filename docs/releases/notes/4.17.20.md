## Impact
This release significantly improves system stability by fixing potential blocking issues in the buffer rotation process. The reordered execution flow ensures that buffers are processed before waiting for other operations to complete, preventing potential deadlocks. The added file path truncation limit ensures predictable system behavior even with large file counts. These changes enhance overall system reliability and ensure more consistent data processing, particularly during shutdown sequences.
