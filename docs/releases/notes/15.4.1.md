# Release 15.4.1

## Bug Fixes

### Athena datalake Glue partition layout heal

- Automatically rebuild unpartitioned Glue datalake tables when Skippr expects time-based partition keys (`year`/`month`/`day`) and the table has no registered Glue partitions.
- Heal runs during schema sync and partition registration instead of failing with a hard partition key count mismatch.
- Prevents Athena sink runtime crashes (`Broken pipe`) when legacy tables were created without partition keys but WAL compaction writes hive-style paths.
