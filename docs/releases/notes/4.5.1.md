# Release Notes for Version 4.5.1

## Performance Improvements

### Thread Management
- Enforced a minimum of 2 CPU threads for processing
- Improved system stability by preventing single-threaded operation
- Enhanced parallel processing capabilities

### Technical Details
- Modified thread allocation to use at least 2 threads, even on single-core systems
- Fixed potential thread starvation issues
- Optimized thread utilization for better performance
- Prevented system from jamming up in single-threaded mode
