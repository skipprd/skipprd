# Version 4.11.0 (August 17, 2023)

This release extends S3 data source support to the developer version of the software, making AWS S3 integration available to all users. The update also includes improvements to logging and API key handling.

## Changes

- **S3 Support**: Extended S3 data source support to developer version
- **Logging**: Enhanced logging system with default API key for developer version
- **API Integration**: Improved API key handling and authentication

## Technical Details

### S3 Integration
- Enabled S3 data source plugin for all users
- Removed license requirement for S3 functionality
- Enhanced S3 client configuration
- Improved S3 connection handling
- Streamlined S3 plugin initialization

### Logging Enhancements
- Added default API key for developer version
- Improved logging system configuration
- Enhanced metrics reporting
- Better error handling in logging
- Improved log message formatting

### API and Authentication
- Implemented default API key for developer version
- Enhanced API authentication handling
- Improved token management
- Better error handling for API requests
- Enhanced security measures

### Code Quality
- Removed deprecated code comments
- Enhanced error handling
- Improved code organization
- Better documentation
- Cleaner plugin initialization
