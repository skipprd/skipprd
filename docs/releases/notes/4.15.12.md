# Release 4.15.12 (November 13, 2023)

## Overview
This release reverts the buffer file compression feature due to data integrity concerns.

## Changes
- **Data Integrity**: Removed buffer file compression to prevent data loss
- **File Handling**: Reverted to uncompressed file storage
- **Reliability**: Improved data consistency in buffer system

## Technical Details
- Removed GZIP compression from buffer file handling
- Reverted parquet serialization to use uncompressed input files
- Removed compression-related code from file writing operations
- Simplified buffer management by eliminating compression overhead
- Enhanced data reliability by ensuring complete data preservation
- Improved error handling in parquet serialization process
