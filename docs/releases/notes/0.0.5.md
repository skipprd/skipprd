# Release 0.0.5

## Features
- Major performance optimization for JSON line processing
- Improved error handling in JSON deserialization
- Enhanced handling of malformed JSON lines
- Added support for processing mixed JSON formats

## Technical Details
- Modified `src/serdes/json.rs`:
  - Implemented new line-by-line JSON processing algorithm
  - Added separate handling for valid and invalid JSON lines
  - Improved error recovery for malformed JSON
  - Enhanced regex-based JSON cleaning
  - Added support for processing mixed format JSON files

## Performance Improvements
- Optimized JSON line processing by:
  - Separating valid and invalid JSON handling
  - Reducing unnecessary string operations
  - Improving error recovery efficiency
  - Adding early return for valid JSON lines

## Impact
These changes significantly improve the performance and reliability of JSON processing, especially for large files with mixed or malformed JSON content. The new implementation provides better error handling and recovery while maintaining high processing speed.

## Notes
This release focuses on performance optimization and improved error handling in the JSON processing system, making it more efficient and robust when handling various JSON formats and potential errors.
