# Version 5.6.0

## Changes
- Added local metadata caching to reduce API calls
- Disabled automatic decoding of escaped JSON strings
- Disabled metrics and configuration uploads to Skippr SaaS

## Technical Details

### Metadata Management
- Implemented local file-based caching of pipeline metadata
- Created directory structure for storing metadata by environment, workspace, and pipeline
- Added file read/write operations for metadata persistence
- Maintained backward compatibility with API-based metadata retrieval
- Improved pipeline start-up reliability by reducing dependency on API availability

### JSON Processing
- Removed automatic decoding of escaped JSON strings
- Fixed issue where fields with JSON-encoded strings were being dropped
- Enhanced support for complex data structures in JSON format
- Improved data fidelity by preserving original string encoding

### API Communication
- Disabled metrics uploads to reduce unnecessary API calls
- Removed configuration uploads as Skippr SaaS support is currently not active
- Improved performance by reducing network overhead
- Enhanced offline operation capability

### Performance Improvements
- Reduced startup time by eliminating unnecessary API calls
- Improved reliability for environments with limited connectivity
- Decreased system resource usage by caching metadata locally
- Enhanced resilience to network interruptions
