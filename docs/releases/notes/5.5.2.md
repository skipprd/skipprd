# Version 5.5.2

## Changes
- Fixed slow schema discovery on x86 platforms
- Improved deadletter handling with enhanced error information
- Added option to ignore S3 list continuation tokens
- Enhanced schema evolution error reporting

## Technical Details

### Performance Improvements
- Fixed critical performance issues with schema discovery on x86 architectures
- Optimized record unwrapping and analysis for faster processing
- Added early return conditions to prevent unnecessary record processing
- Improved handling of large record batches during discovery

### Error Handling
- Enhanced deadletter format with additional contextual information
- Added namespace, partition, and timestamp data to deadletters
- Improved error messages for failed schema evolutions
- Added detailed error reporting for field metadata issues

### S3 Integration
- Added option to ignore S3 list continuation tokens for more reliable operation
- Improved handling of S3 listing operations
- Enhanced file discovery mechanisms

### Code Refactoring
- Restructured record analysis process for better reliability
- Improved return value tracking for schema analysis functions
- Enhanced unwrapping of nested record structures
- Added proper handling for array-type records in schema discovery

## Impact
- Faster schema discovery
- Better performance on x86
- Improved record analysis
- Enhanced system efficiency
- Enhanced error handling and reporting
- Improved S3 integration

## Notes
This release fixes slow schema discovery on x86 architecture by improving record analysis counter handling and synchronization. It also includes improvements to deadletter handling, S3 integration, and schema evolution error reporting.
