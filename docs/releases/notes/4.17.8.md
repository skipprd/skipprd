# Release 4.17.8 (November 25, 2023)

## Overview
This release enhances the buffer file management system by implementing continuous buffer file monitoring and improved rotation logic.

## Changes
- **Buffer Management**: Implemented continuous monitoring of buffer files
- **File Rotation**: Added size and time-based rotation checks
- **System Reliability**: Improved buffer flushing mechanism

## Technical Details
- Removed conditional check for force parameter in buffer file processing
- Added new `OutputFile` struct implementation for tracking file metadata:
  - File size
  - Last update timestamp
  - File handle
  - Rotation status
- Implemented file rotation checks based on:
  - File size thresholds
  - Time-based thresholds
- Enhanced file metadata tracking using UNIX epoch timestamps
- Added proper error handling for file metadata access
- Files are now continuously monitored and rotated based on configurable criteria rather than just force parameter
