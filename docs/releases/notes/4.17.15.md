# Release 4.17.15

*Released: Sun Nov 26 14:11:13 2023*

## Overview
This release enhances file metadata handling with more robust error checking and empty file detection.

## Changes
- **Enhanced Metadata Handling**: Improved the way file metadata is retrieved and validated.
- **Empty File Detection**: Added explicit checks for empty files with appropriate logging.

## Technical Details
- Modified `BufferChunker` to perform separate metadata retrieval using `fs::metadata` instead of relying on file handle metadata.
- Added explicit length checking to skip empty files early in the process.
- Improved error handling and logging for metadata-related operations.
- Separated metadata retrieval and validation into distinct steps for better error control.

Note: This change was later reverted and reimplemented in a different way in version 4.17.16.
