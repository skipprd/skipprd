# Skipprd

[![CI](https://github.com/skipprd/skipprd/actions/workflows/ci.yml/badge.svg)](https://github.com/skipprd/skipprd/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/skipprd/skipprd)](https://github.com/skipprd/skipprd/releases)

Skipprd is the self-hosted ELT engine. Configure a `skippr.yml`, then run `skipprd discover` and `skipprd sync`.

This repository is **source-available** under [PolyForm Shield 1.0.0](./LICENSE), not OSI open source.

Licensor Line of Business: Skipprd ELT engine (https://elt.skippr.io)

Docs: https://elt.skippr.io

```bash
brew tap skipprd/tap
brew install skipprd
```

Or download linux x86_64 / darwin arm64 tarballs from [GitHub Releases](https://github.com/skipprd/skipprd/releases).

Cloud `skippr` is a different binary ([install.skippr.io](https://install.skippr.io)). Data Engineer is [`sde`](https://github.com/skipprd/sde). Managed Cloud ELT is [skippr.io/elt](https://skippr.io/elt/).
