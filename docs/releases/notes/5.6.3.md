# Version 5.6.3

## Changes
- Stopped automatic replacement of single quotes in JSON values
- Updated GitHub Actions artifact version from v2/v3 to v4

## Technical Details

### JSON Parsing Improvements
- Removed automatic conversion of single quotes to double quotes in JSON values
- Fixed issue where valid data containing single quotes was being dropped
- Added a comment to make single quote handling configurable in future versions
- Maintained unicode string handling for backwards compatibility

### CI/CD Updates
- Updated GitHub Actions artifact version from v2/v3 to v4 across all workflow files:
  - actions/upload-artifact
  - actions/download-artifact
- Enhanced reliability of the CI/CD pipeline with latest GitHub Actions components

### Bug Fixes
- Fixed data loss issue where records containing valid single quotes were being dropped
- Maintained compatibility with existing JSON parsing logic while improving data handling
