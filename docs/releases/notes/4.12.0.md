# Version 4.12.0 (August 21, 2023)

This release introduces experimental CSV input support, enhanced performance monitoring through RwLock profiling, and significant improvements in file handling and data processing. The changes focus on expanding input format support while maintaining system stability and performance.

## Changes

- **CSV Support**: Added experimental CSV input format support
- **Performance Monitoring**: Introduced RwLock profiling for better performance tracking
- **File Processing**: Enhanced file handling for various formats
- **Memory Management**: Improved memory usage in data processing
- **Error Handling**: Enhanced error reporting and recovery

## Technical Details

### CSV Input Support
- Added experimental CSV input format support via configuration flag
- Implemented intelligent delimiter detection (comma, semicolon, tab, pipe)
- Automatic header row detection and field mapping
- Support for headerless CSV files with numeric field names
- Flexible CSV record processing with error recovery

### Performance Monitoring
- Introduced TimedRwLock for performance profiling
- Added detailed lock timing statistics
- Enhanced lock contention monitoring
- Improved performance metrics reporting
- Configurable profiling through environment variables

### File Processing Improvements
- Enhanced handling of compressed files (gz, tar, tar.gz, zip)
- Improved line-by-line processing for large files
- Better memory management for file reading
- Enhanced batch processing for optimal performance
- Support for various file encodings and formats

### Memory Optimization
- Improved buffer management for file processing
- Enhanced batch size handling for optimal memory usage
- Better memory allocation for CSV processing
- Reduced memory footprint for null value handling
- Optimized string handling in file processing

### Error Handling and Logging
- Enhanced error reporting for file processing
- Improved error recovery in CSV parsing
- Better logging of performance metrics
- Enhanced debug information for lock contention
- Improved error messages for configuration issues

### Code Quality
- Refactored file processing logic for better maintainability
- Enhanced test coverage for CSV processing
- Improved code organization for lock monitoring
- Better documentation of performance profiling
- Enhanced error handling patterns
