# Release 4.17.10 (November 25, 2023)

## Overview
This release modifies the logging behavior in the S3 input plugin to provide more frequent feedback about skipped objects during processing.

## Changes
- **Logging Enhancement**: Increased frequency of logging for skipped S3 objects
- **Feedback**: Improved visibility into S3 object processing status

## Technical Details
- Removed the threshold condition (100,000 objects) for logging skipped objects in S3 input plugin
- Now logs the number of skipped objects after each batch, regardless of the count
- This change provides more granular feedback about objects that have already been processed
- Helps in monitoring the progress of S3 object processing more effectively
