# Release 4.15.4 (November 4, 2023)

## Overview
This release enhances configuration management and AWS Athena integration, with improvements in environment variable handling and workgroup management.

## Changes
- **Configuration Management**: Added support for running without a config file, using environment variables
- **AWS Athena Integration**: Enhanced workgroup management with automatic updates
- **Event Processing**: Fixed flatten events functionality
- **Plugin Configuration**: Improved plugin name resolution when using environment variables

## Technical Details
- **Configuration System Improvements**:
  - Added support for running without a `skippr.yml` config file
  - Configuration now defaults to empty and builds via environment variables if they exist
  - Fixed plugin name resolution when no config file is present
  - Improved environment variable caching and default value handling

- **AWS Athena Enhancements**:
  - Added capability to update existing Athena workgroups
  - Workgroup output location is now automatically updated when reconfiguring pipelines
  - Improved error handling and logging for workgroup creation/updates
  - Refactored Athena plugin configuration retrieval for better reliability

- **Event Processing Updates**:
  - Fixed flatten events functionality with proper environment variable handling
  - Improved default configuration for event flattening
  - Enhanced caching of transform configuration values

- **Code Refactoring**:
  - Renamed `get_reset_offset` to `get_reset_offsets` for consistency
  - Improved error handling in configuration file reading
  - Centralized plugin configuration retrieval in Athena plugin
  - Enhanced error messages and logging throughout the codebase
