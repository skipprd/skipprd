# Release 4.17.11 (November 25, 2023)

## Overview
This release removes debug logging from the buffer chunker to reduce log verbosity in production environments.

## Changes
- **Debug Logging**: Removed verbose debug logging from buffer file checks
- **Performance**: Reduced log output volume in production environments

## Technical Details
- Commented out debug print statement in buffer chunker that was logging file details (size, path, and timestamp)
- The removed log was in the buffer file checking logic where it previously output information about each buffer file being processed
