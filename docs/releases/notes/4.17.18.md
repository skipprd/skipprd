# Release 4.17.18

*Released: Sun Nov 26 20:50:14 2023*

## Overview
This release improves the efficiency of the buffer management system in Skippr by optimizing the buffer chunking process.

## Changes
- **Buffer Optimization**: Removed conditional buffer finalization logic and related cleanup processes in the `BufferChunker` module, resulting in more efficient buffer handling.
- **Configuration File**: Added sample configuration file `foo_skippr.yml` with pipeline definitions for various data sources and outputs.

## Technical Details
- Modified `src/buffer/mod.rs` to streamline buffer handling by commenting out unnecessary conditional checks and file pointer removal logic.
- Added a comprehensive configuration template that demonstrates various pipeline configurations for cloud trail, device data, bike hire, and other data systems.
