# Version 1.1.0

## Major Changes

### Buffer Management Improvements
- Enhanced file buffer handling with configurable flush settings
- Improved buffer naming conventions and file organization
- Added exclusive locking mechanism for offset file writing
- Removed internal Skippr fields from ingested messages

### File System Enhancements
- Improved buffer file naming with semantic separators
- Enhanced file locking mechanism for better concurrency
- Added configurable buffer size limits
- Improved buffer finalization process

## Technical Details

### Buffer System Updates
- Renamed partition references to namespace for better clarity
- Updated buffer file naming convention:
  - Changed from `*_part` to `*&temp_part`
  - Changed from `*_finalised_*` to `*&finalised=*`
  - Added `buffer=` prefix for better organization
- Enhanced buffer file management:
  - Improved file locking messages
  - Better error handling during lock operations
  - Enhanced file cleanup processes

### Performance Improvements
- Added configurable flush bytes through environment variables
- Improved buffer size tracking
- Enhanced file streaming capabilities
- Better memory management during buffer operations

### Code Quality
- Updated AWS SDK dependencies
- Improved error handling and logging
- Enhanced type safety in interfaces
- Better code organization and structure
- Updated unit tests for new functionality
