# Release 4.14.3 - October 13, 2023

## Overview
This release enhances configuration management by improving default values handling and adding support for environment variables in S3 plugin configuration. These changes make the system more flexible and easier to configure in different environments.

## Changes
- Added support for S3 plugin environment variables
- Improved configuration defaults handling
- Enhanced pipeline configuration fallbacks
- Improved error handling in configuration retrieval

## Technical Details

### Configuration System Enhancements
- Implemented robust fallback mechanisms for pipeline configuration
- Added default values for critical configuration parameters
- Enhanced error handling in configuration retrieval
- Improved configuration validation and type checking

### S3 Plugin Environment Variables
- Added support for `DATA_SOURCE_S3_BUCKET` environment variable
- Added support for `DATA_SOURCE_S3_PREFIX` environment variable
- Implemented fallback mechanism for S3 plugin configuration
- Enhanced S3 plugin configuration initialization

### Plugin Configuration Improvements
- Added support for `DATA_SOURCE_PLUGIN_NAME` environment variable
- Added support for `DATA_OUTPUT_PLUGIN_NAME` environment variable
- Added support for `DATA_SCHEMA_PLUGIN_NAME` environment variable
- Added support for `DATA_DEADLETTER_PLUGIN_NAME` environment variable

### Default Configuration Enhancements
- Improved default data directory handling (defaults to "./data")
- Enhanced environment handling (defaults to "prod")
- Improved auto-approve configuration (defaults to true)
- Added default buffer thresholds (10MB bytes, 60 seconds)

### Error Handling Improvements
- Enhanced error handling in pipeline configuration retrieval
- Improved error messages for configuration issues
- Added graceful fallbacks for missing configurations
- Enhanced logging for configuration-related issues
