# Version 1.1.3

## Major Changes

### Buffer Management Enhancements
- Made buffer flushing limits configurable through environment variables
- Enhanced buffer flushing control mechanisms
- Improved memory management for buffer operations

### Configuration Updates
- Added new environment variables for buffer control:
  - `OUTPUT_FLUSH_BYTES`: Control buffer size limits
  - `OUTPUT_FLUSH_SECONDS`: Control time-based flushing
  - `OUTPUT_FLUSH_RECORDS`: Control record count-based flushing

## Technical Details

### Buffer Configuration Improvements
- Standardized buffer flushing parameters:
  - Default file flush interval reduced to 300 seconds
  - Memory buffer size configurable via `OUTPUT_FLUSH_BYTES`
  - Time-based flushing configurable via `OUTPUT_FLUSH_SECONDS`
  - Record count flushing configurable via `OUTPUT_FLUSH_RECORDS`

### Buffer Tracking Enhancements
- Added record count tracking in memory buffers
- Enhanced buffer size calculation
- Improved buffer chunk management
- Added multiple trigger conditions for buffer flushing:
  - Size-based threshold
  - Time-based threshold
  - Record count threshold

### Code Quality
- Improved configuration management
- Enhanced logging for buffer operations
- Better memory usage tracking
- Improved buffer finalization process
- Added debug logging for buffer chunk operations
