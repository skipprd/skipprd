# Release 4.14.0 - October 11, 2023

## Overview
This major release introduces XML format support, simplifies configuration management, enhances S3 integration, and improves data handling across the system. The release includes significant improvements in configuration file support, plugin management, and data serialization capabilities.

## Changes
- Added XML format support with comprehensive parsing capabilities
- Simplified configuration management with improved defaults
- Enhanced S3 integration and prefix handling
- Improved plugin configuration system
- Added support for configuration files
- Enhanced JSON serialization with better string handling
- Improved metrics tracking and reporting
- Removed PCAP plugin due to dependency constraints

## Technical Details

### XML Support
- Implemented XML serialization and deserialization
- Added support for complex XML structures including nested elements
- Introduced XML to JSON conversion capabilities
- Added comprehensive XML parsing test suite

### Configuration System
- Simplified configuration management with better defaults
- Enhanced environment variable support
- Improved workspace name configuration with default value
- Added support for optional configurations
- Enhanced plugin configuration retrieval
- Implemented configuration file support

### S3 Integration
- Fixed Athena S3 output prefix handling
- Improved S3 bucket and prefix configuration
- Enhanced S3 plugin configuration
- Added better error handling for S3 operations

### Plugin System
- Introduced structured plugin configurations
- Added support for file input plugin configuration
- Enhanced S3 plugin configuration management
- Improved plugin error handling
- Added support for plugin-specific defaults

### Data Processing
- Enhanced JSON string handling
- Improved binary value handling in JSON
- Added support for timestamp coercion to milliseconds
- Enhanced buffer management
- Improved data serialization capabilities

### Metrics and Monitoring
- Enhanced metrics tracking with better timing
- Improved runtime calculation
- Added better error tracking
- Enhanced metrics reporting

### Other Improvements
- Enhanced deadletter handling
- Improved debugging capabilities
- Added support for unique output filenames
- Enhanced test coverage
- Improved error handling across the system
- Removed PCAP plugin to reduce dependency complexity
