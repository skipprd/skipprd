# Version 4.11.2 (August 20, 2023)

This release introduces EULA integration into the software's licensing system and adds query performance reporting features. These changes enhance user awareness of licensing terms and provide better visibility into query execution times.

## Changes

- **Licensing**: Added EULA notification to all commands
- **Query Performance**: Introduced query runtime reporting
- **User Experience**: Enhanced feedback for license validation

## Technical Details

### EULA Integration
- Added EULA notification during license validation
- Included link to online EULA documentation
- Enhanced license validation messaging
- Improved user communication about terms of use
- Better integration of licensing information

### Query Performance Monitoring
- Added query execution time tracking
- Implemented runtime reporting in seconds
- Enhanced query performance visibility
- Improved user feedback for query execution
- Better monitoring of query performance

### User Experience Improvements
- Enhanced license validation feedback
- Clearer messaging about software terms
- Improved command execution feedback
- Better performance metrics visibility
- Enhanced user communication flow
