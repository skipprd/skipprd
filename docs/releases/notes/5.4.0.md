# Version 5.4.0

## Changes
- Added explicit schema discovery mode for safer pipeline initialization
- Improved offset management for better performance
- Added configurable partition value filtering
- Enhanced metrics for WAL index and offsets database
- Fixed error handling for metric network issues

## Technical Details

### Performance Improvements
- Optimized offset commits to occur only on WAL file segment flushes
- Reduced redundant disk I/O operations by eliminating duplicate offset commits
- Improved memory efficiency by passing source data by reference to ingestion threads
- Decreased memory allocations for better overall performance

### Schema Management
- Added dedicated discover mode to safely initialize new ingestion pipelines
- Prevented potential schema clobbering due to network/API errors
- Maintained schema compatibility guarantees for safer evolution
- Improved CLI support for schema discovery via skippr discover command

### Partition Management
- Added partition_allowed_values configuration option
- Implemented filtering of partition values based on allowed list
- Improved handling of high-cardinality fields in partitioning
- Maintained data integrity by still persisting records with non-allowed partition values

### Metrics Enhancements
- Added wal_index_namespaces_total metric to track namespace count
- Added wal_index_partitions_total metric for partition monitoring
- Added wal_index_files_total metric for WAL segment tracking
- Implemented detailed wal_index_metrics for namespace-level partition and segment counts

### Bug Fixes
- Fixed error handling for metric network issues
- Corrected log messages reporting erroneous total ingested messages
- Improved overall error reporting and handling
