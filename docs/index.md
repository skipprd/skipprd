# Skipprd

Skipprd is the self-hosted ELT engine. Run `skipprd discover` and `skipprd sync` from a `skippr.yml`.

This repository is **source-available** under PolyForm Shield 1.0.0, not OSI open source.

```bash
brew tap skipprd/tap
brew install skipprd
# or download linux x86_64 / darwin arm64 from GitHub Releases
skipprd discover
skipprd sync
```

Managed Cloud ELT is a different product: [skippr.io/elt](https://skippr.io/elt/).
Skippr Data Engineer is [`sde`](https://data-engineer.skippr.io).
