# Release 4.15.6 (November 8, 2023)

## Overview
This release simplifies type evaluation and enhances metadata management capabilities, with improved configuration options.

## Changes
- **Type System**: Reverted complex type evaluation for better reliability
- **Metadata Management**: Added metadata reset functionality
- **Configuration**: Enhanced pipeline configuration options
- **Logging**: Improved error messages and logging

## Technical Details
- **Type System Improvements**:
  - Simplified array and record type evaluation
  - Reverted complex type inference rules
  - Enhanced map field handling
  - Improved array field type detection

- **Metadata Management Enhancements**:
  - Added support for resetting metadata via configuration
  - Implemented metadata deletion functionality
  - Enhanced metadata synchronization
  - Added pipeline-specific metadata management

- **Configuration Updates**:
  - Added `reset_metadata` pipeline configuration option
  - Improved configuration initialization process
  - Enhanced environment variable handling
  - Added metadata reset confirmation messages

- **Error Handling Improvements**:
  - Enhanced error messages for map field issues
  - Improved array field error reporting
  - Added detailed logging for metadata operations
  - Enhanced configuration validation messages
