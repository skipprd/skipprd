# Release 4.17.14

*Released: Sun Nov 26 13:36:56 2023*

## Overview
This release optimizes filesystem operations in the buffer system by streamlining file handling and metadata access.

## Changes
- **Filesystem Optimization**: Improved file system operations efficiency in the buffer system.
- **Directory Handling**: Removed directory checks to optimize file processing flow.
- **Metadata Access**: Streamlined file metadata access by using direct file handle methods.

## Technical Details
- Modified `BufferChunker` to use `file.len()` instead of separate metadata calls for file size.
- Removed redundant directory checks in file processing loops.
- Simplified metadata access by using file handle's metadata directly.
- Added `Length` trait from parquet for improved file length handling.
- Improved error handling for metadata access with immediate continuation on errors.
