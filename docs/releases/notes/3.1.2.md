# Version 3.1.2 Release Notes

## Schema Discovery Improvements
- Prevented type discovery for empty or null fields
- Added support for placeholder fields that will be implemented as structs later
- Enhanced schema synchronization to metadata output on startup
- Improved handling of schema evolution during sync operations

## Empty Field Handling
- Added robust handling of empty event type fields
- Improved namespace field parsing for empty and missing fields
- Enhanced partition field handling for empty values
- Added prefix 'p_' to partition field names for better organization

## Technical Details
- Refactored schema synchronization logic:
  - Moved schema sync functionality to a separate method
  - Added automatic schema sync on startup
  - Improved error handling for missing metadata
- Enhanced field value processing:
  - Skip type discovery for null or empty string values
  - Improved handling of nested field structures
  - Added safeguards against empty field names in namespace parsing
- Added test coverage:
  - New tests for empty field handling in partitions
  - Additional tests for namespace field parsing with empty and missing fields
  - Improved test coverage for edge cases
