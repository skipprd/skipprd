# Release 15.5.0

## Improvements

### Compactor drain logging

- Replace vague "no grouped compaction finished" INFO messages with a concrete drain heartbeat: elapsed time, WAL progress bar, per-interval deltas, backlog counts, and condensed active-job state (phase, timeouts, wal_parts).
- Move the full verbose `active_grouped=[...]` drain line to DEBUG for operators who need deep detail.
