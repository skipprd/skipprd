# Release 4.17.17

*Released: Sun Nov 26 20:18:45 2023*

## Overview
This release fixes a critical issue with metadata handling and improves error handling in the Athena plugin.

## Changes
- **Metadata Synchronization Fix**: Fixed an issue where schema synchronization was happening before metadata was properly set in the global state.
- **Athena Plugin Improvements**: Enhanced error handling for missing metadata in the Athena output plugin.

## Technical Details
- Moved `Config::sync_schema` call to after metadata is properly set in the global state to ensure correct synchronization.
- Added robust error handling in `plugins/athena.rs` for cases where namespace metadata is missing, preventing potential panics.
- Improved error messaging to help diagnose metadata-related issues.
