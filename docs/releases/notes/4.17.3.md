# Release 4.17.3 (November 23, 2023)

## Overview
This release improves error handling and logging in the parquet serialization process to provide better context for debugging issues.

## Changes
- **Error Handling**: Enhanced parquet serialization error tracking
- **Logging**: Improved error context in parquet writer

## Technical Details
- Modified parquet serialization error handling:
  - Added error tracking to maintain the last encountered error
  - Reduced immediate error logging to prevent log spam
  - Added error context when closing the parquet writer
  - Improved error message correlation between batch processing and writer closure
- Streamlined error reporting:
  - Now stores batch processing errors for later context
  - Reports errors during writer closure with relevant batch context
  - Provides better debugging information for serialization failures
