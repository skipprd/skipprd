# Version 4.17.25

## Changes

### Buffer Management Improvements
- Enhanced buffer rotation with double flush to ensure all buffers are processed
- Improved buffer file processing with more targeted glob patterns
- Simplified file collection logic for better performance
- Enhanced buffer finalization during shutdown

### File System Operations
- Improved buffer file processing by targeting only merged files
- Enhanced file globbing for better performance and reliability
- Modified buffer rotation sequence to ensure all files are properly finalized
- Added additional buffer rotation call during shutdown to guarantee all data is processed

## Technical Details
- Modified `src/buffer/mod.rs` to improve buffer file globbing with more specific patterns
- Updated `src/main.rs` to call buffer rotation twice during shutdown for complete processing
- Enhanced buffer file collection to improve performance during rotation
- Simplified file iteration logic for better maintainability
- Improved error handling during buffer processing

## Impact
This release focuses on improving the reliability of buffer processing, particularly during system shutdown. The double buffer rotation ensures that all data is properly finalized and persisted, preventing potential data loss. The improved file globbing patterns target only relevant files, improving performance and reducing unnecessary operations. These changes enhance overall system stability and data integrity, especially in high-volume processing scenarios.
