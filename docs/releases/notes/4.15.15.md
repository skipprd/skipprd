# Release 4.15.15 (November 13, 2023)

## Overview
This release adds debugging improvements to help track file processing in the buffer system.

## Changes
- **Debugging**: Added file processing logging in buffer chunker
- **Monitoring**: Improved visibility of file operations

## Technical Details
- Added debug logging to display filenames during buffer processing
- Enhanced monitoring of file operations in the buffer chunker system
- Improved visibility of file processing workflow
- Maintained existing file handling logic for temporary files
