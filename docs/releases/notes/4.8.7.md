# Release 4.8.7

Release Date: August 2, 2023

## Changes

### Improvements
- Enhanced error handling and logging system:
  - Switched from HashMap to BTreeMap for better log organization
  - Added timestamp to each log entry
  - Improved log structure with proper time tracking
  - Re-enabled and fixed global logger functionality
  - Added proper error handling in Athena plugin for file operations
  - Added better error handling for time partition parsing
  - Added tracking for skipped objects in S3 input plugin

### Bug Fixes
- Fixed panic handling to properly log errors before shutdown
- Improved graceful shutdown with proper log flushing
- Added better error handling for file operations and time partition parsing in Athena plugin
- Fixed potential unwrap issues in partition value extraction
