# Version 0.18.0-alpha

## Major Changes

### Test Infrastructure Improvements
- Restructured CI/CD pipeline stages for better test organization
- Added support for different test suites (Unit, Feature, Integration) with configurable test environments
- Introduced new test Dockerfile with improved test environment setup
- Added PHPStan for static code analysis

### Docker Configuration
- Updated base PHP Docker image from `ubuntu-v2.2.5` to `ubuntu-v2.2.6`
- Enhanced test environment with additional dependencies (nodejs, npm, yarn)
- Improved SSH key handling for secure repository access
- Streamlined Docker build process with optimized layer caching

### Dependency Management
- Simplified plugin dependencies by focusing on core file input/output plugins
- Removed several optional data source and output plugins from default installation
- Added PHPStan for enhanced code quality checks
- Retained essential dependencies while reducing overall package footprint

## Technical Details

### CI/CD Pipeline Updates
- Renamed `component-test` stage to `tests` for better clarity
- Added `TEST_SUITE` build argument for flexible test configuration
- Configured separate test stages for Unit, Feature, and Integration tests
- Enhanced test environment with comprehensive dependency installation

### Docker Environment
- Base image updates in both builder and final stages
- Improved test environment with additional development tools
- Enhanced SSH key configuration for secure repository access
- Optimized Docker layer caching with strategic COPY commands

### Dependency Changes
- Focused on core file-based plugins:
  - `skipprd/data-source-file`: dev-develop
  - `skipprd/data-output-file`: dev-develop
- Removed optional plugins to reduce complexity:
  - Kafka-related plugins
  - MQTT subscriber
  - S3-related plugins
  - Salesforce integration
  - AWS Athena output
- Added development dependencies:
  - PHPStan (^0.12.99) for static analysis
  - Retained existing testing frameworks (PHPUnit, Mockery)

### Build Process
- Enhanced test environment setup with comprehensive package installation
- Improved repository access security with proper SSH key handling
- Added PHPStan scripts for code quality checks
- Streamlined plugin dependencies for better maintainability

### Notes
This alpha release focuses on improving the testing infrastructure and simplifying the core package dependencies. The removal of optional plugins allows for a more focused and maintainable codebase, while the enhanced test suite provides better quality assurance capabilities.
