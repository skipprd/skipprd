## Changes

### Performance Optimizations
- Significant improvements to fast path ingestion performance
- Enhanced memory efficiency and reduced allocations
- Optimized thread pool management for better resource utilization
- Improved S3 input processing with better batching and resource management

### Technical Details

#### Fast Path Ingestion
- Refactored `fast_ingest.rs` for better performance:
  - Removed unnecessary cloning and allocations
  - Optimized object handling and value resolution
  - Improved error handling and validation
  - Enhanced map field processing with pre-allocated capacity

#### Thread Pool Management
- Implemented smarter thread pool sizing based on system characteristics
- Added exponential backoff for thread waiting to reduce CPU usage
- Improved memory ordering with AcqRel semantics
- Better handling of high-core count systems

#### S3 Input Processing
- Optimized S3 download concurrency with adjusted semaphore limits
- Implemented batch processing for similar file types
- Separated gzip and regular file processing for better efficiency
- Pre-allocated vectors with known capacities
- Reduced context switching in file processing

### Impact
These changes provide significant performance improvements across the system, particularly for:
- High-volume data ingestion scenarios
- Systems with many CPU cores
- S3-based data processing
- Memory-intensive operations

The optimizations focus on reducing resource contention, improving memory efficiency, and better handling of concurrent operations while maintaining system stability.
