# Version 5.0.0

## Changes

### Performance Optimization
- Limited attempts to get objects from S3 to prevent processing delays
- Reduced max_empty_objects from 100 to 2 in S3 input plugin
- Improved handling of slowly arriving objects to ensure pipeline progression

### Monitoring and Logging
- Enhanced metrics logging with conditional output
- Added detailed performance metrics reporting when messages are processed
- Improved runtime and lock duration reporting
- Suppressed unnecessary buffer ingestion log messages

### Pipeline Flow Control
- Modified pipeline execution to allow SQL commands to run even when pipeline is disabled
- Changed pipeline flow control to check SQL commands before checking if pipeline is enabled
- Improved pipeline status reporting

### Bug Fixes
- Updated message when waiting for ingest tasks to complete for better clarity
- Fixed metrics reporting to only show when relevant changes occur

## Technical Details
- Modified S3 input plugin to avoid getting stuck on slow drip of objects
- Enhanced metrics reporting with conditional display based on message activity
- Reorganized pipeline flow control in main.rs to prioritize SQL command execution
- Improved status messages for better operational visibility

## Impact
This release focuses on performance optimizations and improved observability. The changes to S3 object handling prevent pipelines from getting stuck when processing slow streams of data. Enhanced metrics reporting provides better visibility into system performance, while the pipeline flow control improvements allow for more flexible operation even when pipelines are disabled.
