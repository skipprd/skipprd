# S3

The S3 destination writes files to a bucket prefix.

## Before you begin

- A bucket and prefix Skipprd can `PutObject` to.
- AWS credentials in the environment or an instance role.

```bash
export AWS_ACCESS_KEY_ID="..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_DEFAULT_REGION="us-east-1"
```

## Configure

::: code-group

```python [Python]
from skippr import Config, DataSinkS3, Pipeline

cfg = Config.discover()
raw = cfg.data_sink("raw", DataSinkS3(s3_bucket="acme-landing", s3_prefix="skipprd/events"))
cfg.pipeline("events", Pipeline(data_source=cfg.get_data_source("sample"), data_sink=raw))
cfg.save()
```

```bash [CLI]
skipprd connect data-sink s3 \
  --pipeline events \
  --name raw \
  --s3-bucket acme-landing \
  --s3-prefix skipprd/events
```

```yaml [YAML]
data_sinks:
  raw:
    S3:
      s3_bucket: acme-landing
      s3_prefix: skipprd/events
```

:::

## Options

| Key | Type | Required/Default | Description |
|---|---|---|---|
| `s3_bucket` | string | Required | Destination bucket |
| `s3_prefix` | string | Required | Key prefix |
| `format` | string | Not set | For pipeline type `ingest`, set `format` on this data sink to `parquet` or `jsonl`. For pipeline type `copy`, set `format` on this data sink to `jsonl`, `csv`, or `xml`. If you omit `format` on a copy pipeline, the data sink follows the source: json → jsonl, csv → csv, xml → xml. In pipeline type `copy`, nested objects and arrays in CSV are written as compact JSON strings. When pipeline type is `copy`, the deadletter sink still writes `parquet` or `jsonl`; it does not follow a `csv` or `xml` data sink. |
| `endpoint_url` | URL | Not set | S3-compatible endpoint |

A retry overwrites the same key, so the final objects hold each row once.

## How data lands

Objects land at `s3://<bucket>/<prefix>/<namespace>/…`.

- `<prefix>` is `s3_prefix`.
- `<namespace>` is the source namespace (table or stream name).
- Optional partition folders follow the namespace: `p_country=GB/` from `batch_partition_fields`, and `year=2026/month=10/day=9/` from `batch_time_fields` (or `p_year=…` when `time_partition_prefix` is `p_`).
- The file name is the batch identity plus the `format` extension, for example `apply-0001.jsonl`.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `AccessDenied` | Grant `s3:PutObject` and `s3:ListBucket` |
| `NoSuchBucket` | Check the bucket name and region |
| Wrong endpoint | Set `endpoint_url` for MinIO or another S3 API |
