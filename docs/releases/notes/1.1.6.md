- Enhanced offset tracking by namespace and partition
- Improved buffer flushing mechanism
- Added commit offsets on buffer flush

### Pipeline Enhancements
- Implemented `skippr_emit` function
- Deprecated need to pass pipeline object to input plugins
- Removed deprecated serde area from output sync() methods

- Improved buffer chunk management
- Added better status tracking and reporting
- Enhanced memory management
