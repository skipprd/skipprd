# Release 4.8.4

Release Date: July 26, 2023

## Changes

### Performance Improvements
- Reduced RwLock usage to prevent deadlocks:
  - Temporarily disabled global logger to reduce lock contention
  - Simplified running semaphores for better concurrency
  - Changed metrics lock from write to read where possible
  - Improved shutdown coordination between input and output processes

### Code Cleanup
- Removed commented out legacy metrics code
- Removed unused metrics update for run_time_seconds
- Added proper AWS SDK error types for S3 operations
- Improved code organization in ingest worker

### Bug Fixes
- Fixed graceful shutdown handling in ingest worker
- Improved error handling in S3 input plugin
- Fixed thread synchronization during shutdown
