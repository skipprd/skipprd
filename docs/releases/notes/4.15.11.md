# Release 4.15.11 (November 13, 2023)

## Overview
This release enhances message processing capabilities and improves temporary file handling in the buffer system.

## Changes
- **Message Processing**: Added support for processing arrays of records
- **Buffer Management**: Improved temporary file handling
- **Data Handling**: Enhanced message unwrapping functionality

## Technical Details
- **Message Processing Improvements**:
  - Added support for unwrapping message paths containing arrays of records
  - Implemented processing of array elements as separate messages
  - Enhanced message batch handling with array support
  - Improved error handling for invalid message formats

- **Buffer System Enhancements**:
  - Added exclusion of temporary files from buffer processing
  - Improved file filtering in the buffer chunker
  - Enhanced temporary file management
  - Prevented processing of incomplete buffer files
