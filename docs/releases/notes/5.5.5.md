# Version 5.5.5

## Changes
- Fixed deadlock issues in schema discovery process
- Improved RWLock wait logging for better debugging
- Enhanced API error handling, particularly for 403 errors
- Fixed configuration default home directory
- Added memory profiling capabilities with Heaptrack

## Technical Details

### Concurrency Improvements
- Fixed critical deadlock issues during schema discovery
- Added logging for RWLock wait times to identify bottlenecks
- Implemented improved locking strategies to prevent deadlocks
- Enhanced concurrency management for better parallelism

### Error Handling
- Improved API error handling with better error messages
- Added special handling for 403 Forbidden responses
- Implemented propagation of system errors (e.g., ulimit reached)
- Enhanced error logging for metric API failures
- Added caching of pipeline configuration when metadata API is unavailable

### CI/CD Enhancements
- Added Heaptrack memory profiling support for Linux environments
- Created GitHub Action configuration for Heaptrack integration
- Improved CI pipeline robustness
- Added test skippr.yml configuration for Heaptrack tests

### Configuration
- Fixed default home directory configuration
- Improved cache consistency when API is unavailable
- Minimized API calls when errors occur to prevent unnecessary load
- Added better logging for configuration issues
