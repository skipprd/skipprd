# Version 0.0.1

Code cleanup and SQL query functionality removal.

## Changes
- Removed SQL query functionality from the codebase
  - Deleted `src/sql/query.rs` file containing SQL query processing logic
  - Removed test Parquet file
- Cleaned up code structure and organization

## Technical Details
- Removed complex SQL parsing and execution logic
- Removed AWS Glue and Athena integration code
- Removed custom date functions and table partitioning logic
- Removed local data querying capabilities

## Developer Experience
- Simplified codebase by removing unused SQL functionality
- Reduced dependencies related to SQL processing
- Improved maintainability by removing complex query handling code

## Features
- Fixed offset validation in ingest process
- Improved WAL (Write-Ahead Log) index handling
- Enhanced file sorting by creation time

## Technical Details
- Modified `src/buffer/ingest_buffer.rs`:
  - Improved offset synchronization logging
  - Enhanced file sorting logic for WAL partitions
  - Optimized offset commit process

- Modified `src/ingest_work.rs`:
  - Fixed offset validation logic
  - Improved batch line offset checking
  - Enhanced offset database validation

## Impact
These changes improve the reliability of the ingest process by fixing issues with offset validation and improving the handling of WAL indices. The changes ensure more accurate tracking of ingested data and better synchronization of offsets to the database.

## Notes
This release focuses on fixing critical issues with offset handling and improving the overall stability of the ingest process.
