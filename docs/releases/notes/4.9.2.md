# Version 4.9.2 (August 6, 2023)

This release restores and improves the event flattening functionality while enhancing CI/CD processes and DynamoDB cleanup operations. The changes focus on data transformation capabilities and operational efficiency.

## Changes

- **Data Processing**: Restored event flattening support
- **CI/CD**: Enhanced pipeline configuration
- **Database**: Improved DynamoDB cleanup process
- **Performance**: Enhanced logging and progress tracking
- **Testing**: Updated test configurations
