# Release Notes for Version 4.5.2

## Monitoring and Logging Improvements

### Enhanced Batch Processing Metrics
- Added detailed batch processing summary after each batch
- Introduced smart byte size formatting (B, MB, GB, TB)
- Added clear reporting of batch-level statistics

### Batch Statistics
- Number of messages ingested
- Number of messages fixed
- Number of deadletters
- Total bytes processed with appropriate unit scaling

### S3 Error Handling
- Improved S3 error reporting with more detailed service error information
- Enhanced error visibility for S3 operations

### Technical Details
- Added human-readable byte size formatting with automatic unit selection
- Improved batch processing visibility with detailed metrics
- Enhanced error handling in S3 input plugin
