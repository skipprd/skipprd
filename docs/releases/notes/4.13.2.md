# Release 4.13.2 - September 14, 2023

## Overview
This release introduces support for PCAP (Packet Capture) network data input and includes various minor improvements to data handling and error reporting. The PCAP support enables real-time network traffic analysis and processing within the data pipeline.

## Changes
- Added PCAP network data input support
- Enhanced data ingestion handling
- Improved error reporting for data queries
- Refined packet processing and JSON conversion

## Technical Details

### PCAP Integration
- Added new `DataSourcePcapPlugin` for network packet capture
- Implemented real-time packet processing and JSON conversion
- Added support for both IPv4 and IPv6 packet analysis
- Included detailed packet metadata extraction:
  - Timestamps (seconds and microseconds)
  - Packet lengths (capture and actual)
  - IP versions and addresses
  - Protocol information
  - Port numbers

### Data Processing Improvements
- Enhanced empty record handling in data ingestion
- Improved record counting and offset tracking
- Added better buffer management for network data
- Implemented efficient packet-to-JSON conversion

### Error Handling
- Enhanced error reporting for table data queries
- Added detailed error context for data access issues
- Improved error messages for data processing failures
- Added better error handling for network packet processing

### Performance Optimizations
- Implemented efficient buffer management for network data
- Added configurable buffer sizes and timeouts
- Enhanced data flushing mechanisms
- Improved memory usage in packet processing

### Configuration
- Added support for network interface configuration
- Implemented configurable buffer thresholds
- Added packet capture timeout settings
- Enhanced plugin configuration handling
