# Release Notes - Version 4.4.7

## CI/CD Improvements
- Enhanced Docker container configuration for data persistence

- Updated data directory paths for better consistency

- Applied consistent volume mounting across all test scenarios:
  - S3 plugin tests
  - Flatten transformation tests
  - Event type tests
  - Time bucket tests
  - Small files tests
  - S3 inventory plugin tests
