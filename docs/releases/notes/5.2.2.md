# Version 5.2.2

## Changes
- Added retry mechanism for schema reading from files
- Enhanced WAL partition logging with time tracking
- Improved credential profile validation
- Added schema hash waiting for newly discovered namespaces
- Fixed intermittent IO errors with network file systems

## Technical Details

### File System Reliability
- Implemented retry mechanism for reading schema from files
- Added resilience against intermittent IO errors on network file systems (e.g., EFS)
- Enhanced logging for file operations
- Added waiting mechanism with timeout for schema reads

### Monitoring Improvements
- Enhanced WAL partition logging with elapsed time tracking
- Added detailed file size monitoring in logs
- Improved debugging information in log messages
- Implemented metrics for schema read wait times

### Credential Management
- Added validation to ensure specified profiles exist in credentials file
- Improved error messaging for missing profiles
- Enhanced handling of default profiles
- Better support for local work without profile configuration

### Concurrency Handling
- Added wait mechanism for schema hash on newly discovered namespaces
- Implemented thread coordination for schema processing
- Reduced verbose logging in production environments
- Improved stability for concurrent operations
