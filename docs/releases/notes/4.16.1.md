# Release 4.16.1 (November 16, 2023)

## Overview
This release improves array handling and metadata management, with a focus on performance and stability in array processing.

## Changes
- **Array Processing**: Enhanced array value handling with graceful fallback to null values
- **Metadata Management**: Restored dual-metadata system for better schema evolution
- **Logging**: Reduced debug logging verbosity
- **Performance**: Improved array processing performance

## Technical Details
- **Array Processing Improvements**:
  - Added null value fallback for array elements that don't match expected data type
  - Removed array evolution support temporarily to improve performance
  - Streamlined array element processing with better error handling
  - Maintained array structure while handling type mismatches

- **Metadata System**:
  - Reverted deprecation of NEW_METADATA system
  - Restored metadata synchronization for schema evolution
  - Re-implemented metadata cloning and extension logic
  - Improved handling of schema updates during runtime

- **Logging Enhancements**:
  - Removed verbose filename debugging output
  - Commented out array metadata debugging messages
  - Reduced noise in development logs

- **Performance Optimizations**:
  - Improved array processing speed by avoiding slow path for type mismatches
  - Streamlined metadata handling during schema updates
  - Enhanced buffer management with reduced logging overhead
