# Version 3.1.1 Release Notes

## S3 Object Name Handling
- Added URL decoding for S3 object names to properly handle special characters and spaces
- Implemented consistent URL decoding across all S3 operations
- Enhanced compatibility with encoded object keys in S3 buckets

## Technical Details
- Added URL decoding in S3 input plugin:
  - Applied to object key retrieval operations
  - Implemented in asynchronous object fetching
- Enhanced S3 inventory plugin:
  - Added URL decoding for inventory file access
  - Improved handling of encoded keys in inventory listings
  - Applied consistent decoding across all object operations
- Maintained backward compatibility with existing S3 object naming conventions
- Improved robustness when dealing with special characters in object names
