# Version 1.4.0

## Major Changes

### Performance Improvements
- Removed blocking sleep at the end of shutdown process
- Optimized pipeline shutdown sequence for faster termination
- Enhanced stream connection handling during analysis runs

### Architecture Enhancements
- Relocated schema validation to main command handler
- Improved command flow organization
- Enhanced configuration validation process

### Stream Processing Improvements
- Prevented unnecessary socket server connections during analysis runs
- Optimized sync completion handling
- Added conditional processing for analysis mode

## Technical Details

### Pipeline Command Enhancements
- Moved schema validation logic to PipelineCommand for better control
- Added conditional checks for analysis mode to prevent unnecessary operations
- Improved stream connection management based on operation mode
- Enhanced shutdown sequence with removal of blocking sleep

### Configuration Management
- Improved handling of run modes
- Enhanced configuration validation process
- Added better separation between analysis and normal operation modes

### Code Organization
- Centralized command handling in PipelineCommand
- Improved code structure for better maintainability
- Enhanced error handling and logging during operations
- Optimized command flow for different operation modes
