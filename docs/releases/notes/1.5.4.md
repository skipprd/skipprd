# Version 1.5.4 Release Notes

## Buffer Management Improvements
- Added functionality to unlock and destroy all buffer files during pipeline job reload
- Enhanced buffer file cleanup during reset operations
- Improved buffer file status logging with detailed file information
- Added comprehensive buffer file purging capabilities

## Socket Communication Enhancements
- Implemented non-blocking socket communications between input and output
- Optimized socket handling for improved performance
- Removed blocking operations for better throughput
- Enhanced TCP buffer management

## Logging Improvements
- Enhanced logging to web console with better formatting
- Added ISO8601 timestamps to all log messages
- Improved log message clarity and consistency
- Added detailed buffer file status in log messages

## Technical Details
- Added new `destroyAll()` method for comprehensive buffer cleanup
- Enhanced pipeline reset functionality:
  - Added buffer cleanup during offset reset
  - Improved schema deletion process
  - Added safeguards for file operations
- Improved socket configuration:
  - Set non-blocking mode for better performance
  - Optimized chunk size and buffer settings
  - Enhanced error handling
- Enhanced logging system:
  - Added consistent timestamp formatting
  - Improved log message structure
  - Enhanced error and critical message handling
