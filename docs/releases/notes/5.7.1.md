# Version 5.7.1

## Changes
- Added SQL help command for improved documentation of SQL statements
- Enhanced flattened metadata support for primitive arrays
- Improved schema output conversion
- Added support for field names with special characters and uppercase in flattening
- Added caching for common metadata lookups

## Technical Details

### SQL Documentation
- Added new CLI command `sql-help` to provide documentation for SQL statements
- Implemented command categories for better organization:
  - Schema Operations
  - Pipeline Operations
  - Data Operations
  - Query Operations
- Added support for exporting documentation in multiple formats (md, html, json)
- Included interactive explanation of SQL statements

### Schema Enhancements
- Added support for primitive arrays in record fields
- Improved handling of field names with special characters and uppercase letters
- Enhanced schema output conversion between Skippr and various data formats
- Fixed issues with flattened metadata structure

### Performance Improvements
- Added caching for common metadata lookups to reduce redundant processing
- Optimized field name handling in the flattening process
