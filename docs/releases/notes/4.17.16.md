# Release 4.17.16

*Released: Sun Nov 26 19:50:22 2023*

## Overview
This release improves file metadata handling in the buffer system and simplifies error handling for file operations.

## Changes
- **File Metadata Enhancement**: Improved the way file metadata is retrieved and handled in the buffer system.
- **Error Handling Simplification**: Streamlined error handling for file operations with more graceful fallbacks.

## Technical Details
- Modified `BufferChunker` to use direct file length and metadata access methods.
- Simplified file metadata retrieval logic with automatic fallback to `SystemTime::now()` when metadata cannot be accessed.
- Removed verbose error logging for common file operations and streamlined the code flow.
- Improved handling of file metadata in `OutputFile` creation and management.
