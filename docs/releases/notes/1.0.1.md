# Version 1.0.1

## Major Changes

### Input/Output Enhancements
- Added file input as the default input method
- Implemented filtering functionality during data ingestion
- Added offset testing capabilities

### Build System Improvements
- Added Makefile for common development tasks
- Enhanced code quality checks and automation
- Improved dependency management

## Technical Details

### Build System Updates
- Added new Makefile with commands for:
  - Installation (`make install`)
  - Linting (`make lint`)
  - Code checks (`make check`)
  - Testing (`make test`)

### Code Quality
- Added PHP CodeSniffer for code style enforcement
- Updated composer scripts for better code quality checks:
  - Focused PHPCS and PHPCBF on src directory
  - Enhanced PHPUnit configuration
  - Improved PHPStan analysis setup

### Dependency Updates
- Updated AWS SDK to version 3.201.0
- Added PHP CodeSniffer as development dependency
- Updated various package dependencies:
  - GuzzleHttp Promises to 1.5.1
  - PHPDocumentor reflection-docblock to 5.3.0
  - Other minor package updates

### Testing
- Added new offset testing functionality
- Enhanced test coverage
- Improved test infrastructure

### Documentation
- Added build instructions
- Improved code documentation
- Enhanced development setup documentation
