# Version 4.17.31

## Changes

### Error Handling Improvements
- Improved Parquet serialization error handling
- Added deadletter mechanism for files that fail Parquet serialization
- Enhanced error reporting for file processing failures
- Replaced panic with graceful degradation for serialization errors

### Dependency Management
- Removed erroneous 'io' crate dependency
- Streamlined dependency list in Cargo.toml
- Updated Cargo.lock to reflect dependency changes
- Improved dependency management for better build stability

### Bug Fixes
- Fixed issue with duplicate tenant name handling
- Implemented proper tenant ID cleanup before setting new values
- Enhanced license checking with improved tenant ID management
- Resolved potential data inconsistency with tenant information

## Technical Details
- Modified `src/serdes/parquet.rs` to move files that fail serialization to deadletter directory
- Updated Cargo files to remove unnecessary 'io' crate dependency
- Enhanced `src/helpers/license.rs` to properly clear tenant ID before setting new values
- Improved error reporting with more informative messages
- Added file movement handling for better error recovery

## Impact
This release improves system stability and error handling with a focus on graceful degradation rather than hard failures. The deadlettering of files that fail Parquet serialization prevents pipeline failures while preserving problematic data for later inspection. Dependency cleanup reduces potential conflicts and improves build consistency. The tenant ID fix ensures proper license handling and prevents data inconsistencies when processing tenant information.
