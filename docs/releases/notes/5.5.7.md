# Version 5.5.7

## Changes
- Improved disk usage management by flushing buffers when approaching limits
- Removed S3 prefix shredding and continuation token tracking
- Disabled license API integration
- Made schema synchronization optional on startup
- Optimized CI/CD pipeline for better reliability

## Technical Details

### Buffer Management
- Added disk usage tracking to prevent buffer overflow
- Implemented forced compaction when disk usage approaches configured limit
- Enhanced buffer flushing mechanism with better byte tracking
- Improved WAL (Write-Ahead Log) partition management
- Added 10% headroom calculation to prevent hitting disk limits

### S3 Integration
- Removed S3 prefix shredding functionality due to inconsistent list requests
- Eliminated continuation token tracking to improve reliability
- Enhanced error handling for S3 operations

### Performance Optimizations
- Made schema synchronization optional at startup to improve runtime speed
- Replaced RWLock with direct references for output plugins
- Optimized compaction operations with concurrent processing
- Improved buffer flushing with better byte tracking

### Build and Deployment
- Updated GitHub workflow to exclude specific test tags
- Streamlined release process by focusing on Linux builds
- Updated .gitignore to exclude schema directory
- Fixed CI/CD pipeline for more consistent releases
