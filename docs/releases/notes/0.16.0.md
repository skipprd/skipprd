## Version 0.16.0

### Major Changes

#### Infrastructure Updates
- Migrated ECR repository from `public.ecr.aws/b0z2w1a5` to `public.ecr.aws/skippr`
- Enhanced Docker image management with automatic `latest` tag handling
- Streamlined CI/CD pipeline configuration
- Modernized Docker image publishing workflow

### Technical Details

#### Container Registry
- Updated ECR host configuration to use new Skippr public repository
- Implemented automatic tagging of images with `latest` tag for git-tagged releases
- Removed deprecated AWS ECR commands in favor of native Docker push commands
- Enhanced image tagging process for better version management

#### CI/CD Pipeline
- Modified GitLab CI configuration to work with new ECR repository
- Improved Docker image publishing workflow
- Streamlined manifest handling using direct Docker commands
- Enhanced automation of image tagging and publishing

#### Build Process
- Simplified Docker image tagging and publishing
- Improved version management through automated tagging
- Enhanced build pipeline reliability
- Streamlined container registry integration

### Notes
This release focuses on infrastructure improvements, particularly in container registry management and CI/CD pipeline enhancements. The migration to the new ECR repository and modernized Docker workflows provides a more robust and maintainable deployment process.
