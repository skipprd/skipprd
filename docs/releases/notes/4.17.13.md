# Release 4.17.13

*Released: Sun Nov 26 13:29:49 2023*

## Overview
This release optimizes filesystem operations by improving the timing of file existence checks.

## Changes
- **Filesystem Check Optimization**: Moved file existence check to only occur when file rotation is needed.
- **Performance Improvement**: Reduced unnecessary filesystem operations in the buffer finalization process.

## Technical Details
- Modified `BufferChunker::finalise_buffers` to perform file existence check only when a file is due for rotation.
- Moved the `Path::new(filename).exists()` check inside the rotation condition block.
- Improved efficiency by avoiding unnecessary filesystem checks when files are not ready for rotation.
- Maintained the same error handling behavior but with better performance characteristics.
