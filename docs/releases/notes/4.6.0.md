# Release Notes for Version 4.6.0

## Bug Fixes and Improvements

### Offset Management
- Fixed offset handling in the `Offsets` implementation
- Added proper offset type handling for different types (Filesize, Line, Closed)
- Each offset type now correctly stores its value instead of defaulting to zero

### Metrics Reset
- Added proper reset of per-minute metrics
- `bytes_current` and `ingested_current` metrics are now correctly reset every minute

### Test Improvements
- Fixed test cases in fast ingest module by properly initializing metadata HashMaps

### S3 and File Input Plugins
- Improved offset validation logic in file input plugin
- Enhanced offset checking in S3 input plugin with better variable naming
- Refactored S3 inventory plugin for clearer offset validation

## Technical Details
- Improved code readability by extracting offset validation into separate variables
- Fixed potential issues with uninitialized metadata in test cases
- Streamlined metric reset timing in the main sync loop
