# Version 5.3.0

## Changes
- Added configurable prefix for time partitions
- Implemented schema dump to file in Hive format
- Fixed deadletter handling for buffer rows that fail to encode
- Improved pipeline skipping for faster multi-pipeline processing
- Enhanced build process to include all platforms

## Technical Details

### Time Partition Enhancements
- Added configurable prefix for time partitions to avoid field name collisions
- Implemented time partition prefix in S3 path generation 
- Fixed time partition granularity to only calculate up to configured target
- Improved query support for time-partitioned data with custom prefixes

### Schema Management
- Added schema dump to file in Hive format for documentation and inspection
- Included flattening configuration in pipeline metadata for correct schema output
- Fixed schema encoding and decoding error handling
- Enhanced schema consistency between WAL files

### Error Handling
- Improved deadletter handling for buffer rows that fail to encode to record batch
- Fixed atomic order of metrics across threads
- Enhanced logging with reduced verbosity for long-running tasks
- Added better error detection and reporting

### Performance Improvements
- Implemented faster skipping of pipelines that are already ingesting
- Added fsync for new WAL files on creation for improved reliability with slow network drives
- Fixed issue with DROP PIPELINE to ensure proper cleanup
- Optimized build and release process for all platforms

### Build and Deployment
- Restored build support for macOS ARM64 and x86 platforms
- Enhanced GitHub release process to include all platform builds
- Improved CI/CD pipeline reliability
- Removed unnecessary test files and logs
