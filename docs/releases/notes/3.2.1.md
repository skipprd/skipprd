# Version 3.2.1 Release Notes

## Schema and Metadata Management
- Enhanced metadata existence validation for namespaces to prevent unexpected failures
- Improved handling of nested fields with robust existence checks before processing
- Fixed schema flattening functionality to maintain data structure integrity
- Protected against unknown nested fields to prevent processing errors

## Athena Integration Improvements
- Fixed Athena partition creation to preserve flattened schema when enabled
- Prevented unintended schema clobbering in AWS Glue
- Added support for conditional schema flattening based on environment configuration
- Enhanced partition metadata handling with proper namespace validation

## Technical Details
- Added defensive programming for metadata field access:
  - Implemented multi-level existence checks for nested fields
  - Added safeguards against accessing undefined metadata structures
- Optimized schema flattening logic:
  - Removed redundant recursive flattening calls
  - Improved handling of output field names
- Enhanced Athena partition management:
  - Added environment-aware schema transformation
  - Improved error handling for partition creation
  - Implemented proper schema preservation during partition updates
