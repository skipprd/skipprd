# Release 4.17.2 (November 23, 2023)

## Overview
This release focuses on improving log management and error handling, particularly in S3 operations and parquet file processing.

## Changes
- **Logging**: Reduced verbose logging in S3 operations
- **Error Handling**: Enhanced parquet writer error handling
- **Performance**: Optimized log output for S3 operations

## Technical Details
- **S3 Input Plugin**:
  - Disabled verbose logging of skipped objects
  - Maintained counter reset functionality without logging
  - Reduced log volume in production environments

- **S3 Inventory Plugin**:
  - Removed verbose logging of skipped inventory manifests
  - Maintained internal tracking without excessive logging
  - Improved operational efficiency by reducing log output

- **Parquet Writer**:
  - Added proper error handling for writer closure operations
  - Implemented graceful error reporting for writer closure failures
  - Enhanced error visibility for parquet file finalization issues
  - Replaced unwrap with proper error handling pattern
