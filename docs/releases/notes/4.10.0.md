# Version 4.10.0 (August 17, 2023)

This release introduces significant improvements to the release process, Docker container management, and CI/CD pipeline. The changes focus on streamlining deployment and making the software more accessible through automated installation.

## Changes

- **Release Process**: Added GitHub release automation
- **Docker**: Enhanced Docker container configuration
- **Installation**: Added automated installation script
- **CI/CD**: Improved build and test infrastructure
- **Dependencies**: Updated and optimized dependencies

## Technical Details
