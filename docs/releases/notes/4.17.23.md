# Version 4.17.23

## Changes

### Buffer Management Improvements
- Fixed competing buffer writes issue
- Enhanced buffer finalization with per-file approach
- Disabled automatic buffer file globbing during rotation
- Improved handling of buffer files in multi-threaded environment

### File Handling
- Modified buffer file naming to include core count
- Updated file globbing pattern to include all merged files
- Enhanced buffer file finalization timing
- Improved coordination between threads writing to buffer files

### Performance Optimization
- Reduced contention for buffer files in multi-threaded processing
- Enhanced buffer finalization by managing it at the file level
- Improved file access patterns for better concurrency
- Optimized buffer rotation process for multi-core environments

## Technical Details
- Modified `src/buffer/mod.rs` to disable automatic buffer rotation to prevent competing writes
- Updated `src/ingest_work.rs` to handle buffer finalization at the individual file level
- Enhanced file naming convention to include core count for better separation
- Commented out code that could cause competing access to files
- Improved buffer file globbing pattern to match all relevant files
- Added direct call to finalize buffers in ingest work process

## Impact
This release significantly improves system stability in multi-threaded environments by resolving competing buffer writes issues. The enhanced file naming and individual buffer finalization approach ensures that multiple processing threads can operate concurrently without file access conflicts. These changes prevent data corruption and improve overall system reliability, particularly in high-throughput scenarios with multiple processing cores.
