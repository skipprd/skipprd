# Release 4.17.12

*Released: Sun Nov 26 12:30:54 2023*

## Overview
This release introduces a new file buffering system with significant improvements to file handling, buffer management, and synchronization.

## Changes
- **New Buffer System**: Implemented a new file buffering system with improved file handling and synchronization.
- **File Management**: Added support for file tombstoning and better cleanup processes.
- **Performance Optimization**: Reduced buffer rotation interval and improved file synchronization.
- **Error Handling**: Enhanced error reporting in parquet serialization.

## Technical Details
- Replaced static output files with a dynamic buffering system.
- Implemented file tombstoning mechanism to handle file cleanup safely.
- Modified buffer rotation interval from 60 to 5 seconds for more frequent processing.
- Added core-specific file naming for better parallel processing.
- Enhanced file synchronization with explicit flush and sync calls.
- Improved error handling in parquet serialization with more detailed error messages.
- Added support for file extensions in time parsing.
- Updated tests to reflect new file handling mechanisms.
