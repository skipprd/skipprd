# Release Notes for Version 4.5.4

## Bug Fixes and Improvements

### Metrics and Monitoring
- Fixed double counting issue in message total metrics
- Added recovery mechanism for poisoned metric locks
- Improved periodic metric lock handling

### Performance Monitoring
- Re-enabled runtime seconds tracking in metrics
- Restored messages per minute display in logs
- Removed redundant message count increment in batch processing

### Technical Details
- Fixed a bug where messages were being counted twice in the total count
- Enhanced error handling for metric locks to prevent system lockups
- Streamlined metric reporting in periodic tasks
- Improved logging clarity by removing redundant output
