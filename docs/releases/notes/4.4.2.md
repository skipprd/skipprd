# Release Notes - Version 4.4.2

## Metrics Improvements
- Enhanced metrics reporting structure
- Removed redundant `msgs_total` field from metrics
- Added timestamp information to metrics payload using RFC3339 format
- Streamlined metrics data structure for better clarity

## Configuration Enhancements
- Improved environment variable handling
  - Added proper handling of empty string values in environment variables
  - Empty string values now correctly fall back to default values
  - Enhanced robustness of configuration system
- Added unit tests for empty string environment variable handling

## Technical Details
- Updated `Metrics` struct to remove deprecated fields
- Enhanced configuration testing coverage
- Improved default value handling in configuration system
- Added timestamp standardization using `chrono::Utc::now().to_rfc3339_opts()`
