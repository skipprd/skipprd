# Release 4.8.5

Release Date: July 27, 2023

## Changes

### Performance Improvements
- Reduced lock contention to prevent deadlocks:
  - Made PARSE_NAMESPACE_CACHE thread-local
  - Optimized lock usage in metadata handling
  - Improved buffer management and file rotation

### Improvements
- Enhanced metrics reporting:
  - Added ingested_fixed metric
  - Improved calculation of ingested_current metric using atomic counter
  - Added last_update timestamp to metrics
- Improved buffer file rotation:
  - Better error handling and logging for file rotation failures
  - More efficient file path handling
- Added TODO comments for future improvements in buffer management:
  - Individual file locking
  - Parallel buffer flushing
  - Non-blocking operations
  - Persistent file metadata storage

### Bug Fixes
- Fixed metrics calculation for ingestion rates
- Improved graceful shutdown handling
- Fixed file rotation path handling
