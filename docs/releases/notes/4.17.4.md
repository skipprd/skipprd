# Release 4.17.4 (November 23, 2023)

## Overview
This release enhances logging capabilities to provide better visibility into file processing operations and error conditions.

## Changes
- **Logging**: Added output file finalization logging
- **Error Reporting**: Enhanced parquet serialization error logging

## Technical Details
- Added logging to confirm successful output file finalization
  - Now logs the path of each finalized output file
  - Helps track file processing completion
  - Maintains existing error logging for finalization failures

- Enhanced parquet serialization error reporting
  - Added logging for batch reading errors during parquet serialization
  - Improved visibility into serialization issues
  - Helps in debugging data conversion problems
