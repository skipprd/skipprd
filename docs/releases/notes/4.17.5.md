# Release 4.17.5 (November 23, 2023)

## Overview
This release modifies the logging behavior in the S3 input plugin to reduce log verbosity while maintaining visibility for large-scale operations.

## Changes
- **S3 Logging**: Added threshold-based logging for skipped S3 objects
- **Performance**: Reduced log output volume for small batches

## Technical Details
- Modified S3 input plugin logging to only report skipped objects when count exceeds 100,000
- Helps reduce log noise while maintaining visibility for large-scale operations
- Maintains counter reset behavior after logging
- Provides better insight into large-scale S3 object processing operations
