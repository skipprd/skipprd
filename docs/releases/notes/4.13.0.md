# Version 4.13.0 (September 14, 2023)

This release introduces significant improvements in schema evolution and type inference, along with enhancements to the CLI and data processing capabilities. The changes focus on making data type handling more robust and predictable, particularly for complex nested structures and evolving schemas.

## Changes

- **Schema Evolution**: Enhanced schema evolution with improved type inference and field handling
- **CLI Enhancements**: Added new schema CLI mode for inspecting data structures
- **Type Inference**: Improved type inference for boolean, array, and map fields
- **CSV Processing**: Enhanced CSV processing with better delimiter detection
- **Error Handling**: Improved error handling and logging throughout the system

## Technical Details

### Schema Evolution Improvements
- Enhanced field evolution with support for parent field context
- Improved handling of nested field metadata
- Better support for array and map type evolution
- Clearer field type determination for complex structures
- Enhanced boolean to integer type promotion for more accurate schema inference

### Type Inference Enhancements
- Improved map and record type differentiation
- Better handling of boolean values in numeric contexts
- Enhanced array field metadata management
- More accurate type inference for sequential vs. associative arrays
- Support for type demotion in specific scenarios (boolean, date, timestamp)

### CLI and Data Access
- New schema CLI mode for inspecting table structures
- Enhanced schema display with sorted field listing
- Improved table registration and schema querying
- Better handling of workspace and pipeline names
- Enhanced error messages for missing data sources

### CSV Processing Improvements
- Enhanced delimiter detection algorithm
- Better handling of header rows
- Improved newline character handling
- More efficient CSV record processing
- Enhanced error handling for malformed records

### Performance and Reliability
- Optimized type inference for large datasets
- Improved memory usage in CSV processing
- Enhanced error handling and recovery
- Better logging of schema evolution events
- Reduced unnecessary schema updates

### Code Quality
- Improved error messages and logging
- Enhanced test coverage for type inference
- Better handling of edge cases in schema evolution
- Cleaner code organization for schema-related functionality
- Improved documentation of type inference logic
