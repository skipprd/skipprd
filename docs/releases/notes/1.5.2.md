# Version 1.5.2 Release Notes

## Schema Management Improvements
- Enhanced schema deletion process during data reload operations
- Added support for namespace-specific schema deletion
- Improved logging of schema deletion operations
- Added granular control over schema cleanup

## Technical Details
- Modified schema deletion workflow:
  - Added iteration over all namespaces in configuration
  - Implemented namespace-specific deletion calls
  - Enhanced logging with namespace information
- Improved pipeline reset functionality:
  - Added comprehensive schema cleanup
  - Enhanced shutdown procedure
  - Better coordination between offset reset and schema deletion
- Added safeguards for schema operations during data reloads
