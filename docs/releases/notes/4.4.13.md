# Release Notes for Version 4.4.13

## Overview
This release focuses on CI/CD pipeline modifications, specifically commenting out the chaos mode testing configuration in the GitLab CI pipeline.

## Key Changes

### CI/CD Pipeline Updates
- Temporarily disabled chaos mode testing in the GitLab CI pipeline
- Commented out the entire chaos mode test configuration block
- Preserved the configuration for future reference

### Testing Framework
- Maintained the structure of chaos mode tests while disabling execution
- Kept all environment variables and test parameters in comments
- Preserved Soda data quality testing configuration

### Technical Details
- Commented out chaos mode test configuration in `.gitlab-ci.yml`
- Preserved test environment settings including:
  - AWS configuration
  - Data source and output settings
  - Schema and database configurations
  - Pipeline naming and API token settings
- Maintained Docker container configurations and test validation logic

## Developer Notes
The primary focus of this release was to temporarily disable chaos mode testing in the CI/CD pipeline while preserving the configuration for future use. This change allows for more streamlined pipeline execution while maintaining the ability to re-enable chaos testing when needed.
