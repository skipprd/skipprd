# Version 5.6.1

## Changes
- Added support for arrays as objects in JSON processing
- Reintroduced string cleaning for Unicode and single quotes in JSON parsing
- Fixed CSV test issues and improved parsing

## Technical Details

### JSON Parsing Improvements
- Reintroduced stripping of Unicode and single quotes from JSON strings
- Maintained compatibility with existing JSON parsing logic
- Disabled support for escaped JSON in favor of standard JSON format
- Updated tests to reflect the new parsing behavior

### Array Handling
- Added support for processing arrays as objects in JSON data
- Improved handling of primitive arrays within records
- Enhanced metadata handling for array fields
- Fixed field types in array processing to ensure correct schema detection

### Bug Fixes
- Fixed several test cases to align with updated parsing logic
- Corrected CSV parsing to handle multiple rows correctly
- Fixed metadata handling for nested fields
- Improved record field processing with better error handling

### Performance Optimizations
- Enhanced processing of complex nested data structures
- Improved error recovery in JSON parsing
- Optimized memory usage for array handling
- Reduced redundant processing in record field handling
