# Release 4.8.1

Release Date: July 25, 2023

## Changes

### Performance Improvements
- Replaced Mutex with RwLock throughout the codebase to prevent deadlocks:
  - Updated global state management for running flags
  - Enhanced thread synchronization in logger implementation
  - Improved lock handling during shutdown sequences

### Logging Improvements
- Streamlined batch processing logs for better clarity
- Updated license-related messaging
- Enhanced ingest task completion logging
- Improved error logging initialization
