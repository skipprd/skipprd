# Version 1.5.0

## Major Changes

### IonCube Integration
- Added support for IonCube encoding to protect critical code components
- Implemented selective encoding for core functionality modules
- Enhanced security through code obfuscation and binary protection
- Added configuration for IonCube encoder with optimized settings

### File Handling Improvements
- Replaced socket-based binary message framing with file buffering
- Enhanced input and output file buffering for both batch and row-based formats
- Improved line-by-line processing for better memory management
- Added support for handling concatenated JSON objects on single lines

### Infrastructure Updates
- Added support for PHP 7.4 ZTS (Zend Thread Safety)
- Enhanced Docker configurations with multi-stage builds
- Added support for msgpack and parallel extensions
- Improved performance through optimized extension configurations

### Testing Enhancements
- Updated test suite for PHP 7.4 compatibility
- Added new test cases for JSON object handling
- Enhanced test coverage for field name cleaning
- Updated test method signatures for PHPUnit compatibility

## Technical Details

- Configured obfuscation for line numbers with secure key

- Enhanced file buffer driver implementation
- Improved chunked buffer handling
- Added support for efficient processing of concatenated JSON records
- Optimized memory usage in file operations

### Development Environment
- Added comprehensive PHP 7.4 installation instructions

- Enhanced build process with improved Docker stages
- Added support for various PHP extensions and configurations

### Code Quality
- Updated PHPUnit test methods to match PHP 7.4 requirements

- Improved code organization and modularity
