# Release Notes - Version 3.4.1

## New Features
- Added stdin plugin for data input
  - Implemented buffered reading from standard input
  - Added configurable buffer size and timeout settings
  - Integrated with existing ingest pipeline

## Buffering Improvements
- Added buffer support for stdin plugin
  - Configurable buffer size through `DATA_SOURCE_BATCH_SIZE_BYTES`
  - Adjustable buffer timeout via `DATA_SOURCE_BATCH_SIZE_SECONDS`
  - Buffer threshold control with `BUFFER_THRESHOLD_SECONDS`
- Enhanced data processing efficiency with buffered operations

## Metadata Handling Enhancements
- Fixed nested output field name handling during field discovery
- Improved parent field and data type tracking in metadata
- Enhanced metadata flattening logic
- Added unit tests for metadata flattening functionality

## Code Quality Improvements
- Fixed CI/CD configuration
- Enhanced error handling in data processing
- Improved thread management for data ingestion
- Added comprehensive test coverage for metadata operations

## Technical Details
- Updated configuration handling to be more efficient
- Enhanced metadata evolution tracking
- Improved thread synchronization in data processing
- Added support for random partition generation in stdin plugin
- Updated DynamoDB purge script with correct key handling
