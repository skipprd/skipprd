# Release 4.17.7 (November 24, 2023)

## Overview
This release includes significant improvements to data type handling, error reporting, and CLI functionality, along with several critical bug fixes.

## Changes
- **Data Type Handling**: Enhanced integer and timestamp type detection and validation
- **Error Handling**: Improved error reporting for parquet serialization
- **CLI Enhancement**: Added pipeline name option to discover command
- **Bug Fixes**: Fixed timestamp handling and off-by-one error in batch processing

## Technical Details
- **Integer Type Improvements**:
  - Implemented proper 32-bit and 64-bit integer range validation
  - Added comprehensive test suite for integer type detection
  - Fixed type coercion for integer fields
  - Separated handling of int/integer from long types

- **Timestamp Handling**:
  - Fixed timestamp detection and conversion
  - Improved millisecond timestamp handling
  - Added proper type coercion for timestamp fields

- **Error Handling**:
  - Added panic on parquet serialization failure for immediate error detection
  - Improved error messages for invalid data types
  - Enhanced error reporting in batch processing

- **CLI Updates**:
  - Added `--pipeline` option to discover command
  - Made pipeline name mandatory for schema discovery
  - Added proper error message for missing pipeline name

- **Bug Fixes**:
  - Fixed off-by-one error in batch line processing
  - Corrected line number calculation in error reporting
  - Fixed edge cases in batch processing

- **Testing**:
  - Added unit tests for integer type validation
  - Added tests for 32-bit and 64-bit integer range checks
  - Added tests for invalid input handling
