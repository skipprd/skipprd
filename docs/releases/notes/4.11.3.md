# Version 4.11.3 (August 21, 2023)

This release focuses on improving the CI/CD pipeline, specifically enhancing the release process to ensure better coordination between GitHub releases and Docker image publishing.

## Changes

- **CI/CD Pipeline**: Improved release process coordination
- **Docker Publishing**: Enhanced Docker image publishing workflow

## Technical Details

### CI/CD Improvements
- Modified Docker image publishing to wait for GitHub release completion
- Ensured binary availability before Docker image creation
- Enhanced dependency management between CI/CD jobs
- Improved release process reliability
- Better coordination between different release artifacts

### Docker Publishing Workflow
- Updated job dependencies in GitHub Actions
- Improved release timing and sequencing
- Enhanced artifact availability checks
- Better error handling in publishing process
- Improved release process documentation
