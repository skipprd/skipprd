# Version 4.17.29

## Changes

### Buffer Management Improvements
- Fixed competing access to files across threads
- Improved buffer file locking strategy during finalization
- Enhanced file pointer management for rotated files
- Optimized buffer index handling for concurrent operations

### File Processing
- Fixed error handling when file plugin scans directories
- Improved line reading with proper error handling
- Enhanced file globbing to match only relevant files
- Converted asynchronous file operations to synchronous for better consistency

### Performance Optimizations
- Improved buffer rotation process
- Enhanced file metadata handling
- Optimized index file pointer reset for rotated files
- Reduced memory leaks from orphaned file references

## Technical Details
- Modified `src/buffer/mod.rs` to improve buffer file locking and synchronous operation
- Updated `src/plugins/file_input.rs` with better error handling for line reading
- Enhanced `src/ingest_work.rs` to properly reset file pointers after rotation
- Updated buffer index handling to prevent competing access across threads
- Improved file globbing patterns to match only relevant files

## Impact
This release significantly improves system stability in multi-threaded environments by addressing file access contention issues. The enhanced buffer management prevents data corruption when multiple threads attempt to access the same files. Improved error handling for file operations ensures pipelines continue to function even when encountering problematic input files. The optimized buffer rotation process enhances overall system performance while maintaining data integrity.
