# Version 5.5.4

## Changes
- Implemented retry mechanisms for S3 file operations
- Updated major dependencies including Arrow, Parquet, and DataFusion
- Added backoff retry for S3 list requests
- Implemented license result caching to reduce HTTP requests
- Fixed metrics API poller initialization to prevent duplicate planners

## Technical Details

### S3 Integration Improvements
- Added retry logic for S3 file deletion operations
- Implemented exponential backoff for S3 list requests
- Enhanced resilience against transient S3 API errors
- Improved error handling for S3 operations

### Dependency Updates
- Updated AWS SDK to latest version
- Upgraded Arrow from v49.0.0 to v51.0.0
- Updated Parquet and DataFusion libraries
- Removed unused dependencies
- Replaced parking_lot with standard Skippr timed RWLock

### Performance Optimizations
- Added caching for license API results to reduce HTTP traffic
- Ensured metrics API poller is initialized only once
- Reduced API verbosity for improved log readability
- Removed deprecated files to clean up codebase

### Architecture Improvements
- Implemented proof-of-concept for querying Hive + S3
- Made selected functions static for better code organization
- Switched from specific locking libraries to Skippr's custom implementation
- Improved error handling throughout the application
