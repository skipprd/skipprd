# Release Notes - Version 4.3.4

## Athena Integration Improvements
- Fixed Athena Parquet compression, paths, and encoding
  - Enabled SNAPPY compression for Parquet files
  - Improved path handling for S3 locations
  - Enhanced encoding configuration for better compatibility
- Updated table and partition management
  - Added proper compression settings for tables and partitions
  - Improved location URI formatting
  - Enhanced database and table creation logic

## Data Processing Enhancements
- Improved integer type casting from strings
- Enhanced type detection in schema discovery
- Removed hard limit on number of objects to download
- Optimized chunk size handling in S3 operations

## Infrastructure Updates
- Added small files E2E test
- Enhanced CI/CD pipeline with new test scenarios
- Added stable container image release process
- Pinned Docker base image to debian:bullseye-20230522-slim

## Performance Optimizations
- Improved Parquet file handling
  - Enabled SNAPPY compression
  - Configured PLAIN encoding
  - Disabled dictionary encoding for better performance
- Enhanced S3 download management
  - Removed arbitrary object count limits
  - Improved byte threshold handling

## Technical Details
- Updated license validation messaging
- Enhanced path handling using `std::path::Path`
- Improved error handling in Glue operations
- Added comprehensive test configurations for small files
- Enhanced metadata handling in flattened schemas
