# Release 4.14.1 - October 13, 2023

## Overview
This release addresses a critical issue with metadata handling during pipeline synchronization and improves error messaging for plugin configuration. The changes ensure proper isolation between pipeline runs and provide clearer feedback for plugin configuration issues.

## Changes
- Fixed metadata handling between pipeline synchronization runs
- Improved error messages for plugin configuration
- Enhanced API token handling with better defaults
- Refined plugin-related error messages

## Technical Details

### Metadata Management Improvements
- Added metadata reset between pipeline synchronization runs
- Fixed issue where previous pipeline schema was incorrectly retained
- Implemented proper metadata isolation between different pipelines
- Enhanced metadata synchronization process

### Error Message Enhancements
- Improved error messages for missing plugins
- Added buffer name context to plugin error messages
- Enhanced clarity of plugin configuration feedback
- Standardized error message format for plugin-related issues

### Configuration Handling
- Added default empty string for API token when not configured
- Improved API token retrieval with safer fallback
- Enhanced configuration validation for API tokens
- Added graceful handling of missing configuration values

### Plugin System Improvements
- Enhanced plugin error reporting
- Improved plugin configuration validation
- Added better feedback for missing plugin configurations
- Enhanced plugin initialization error handling
