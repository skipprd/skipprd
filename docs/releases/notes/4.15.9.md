# Release 4.15.9 (November 9, 2023)

## Overview
This release enhances file handling safety and improves build process configurations, with a focus on preventing empty file processing.

## Changes
- **File Safety**: Added comprehensive empty file validation
- **Build Process**: Updated macOS build configurations
- **Compatibility**: Added support for legacy buffer files

## Technical Details
- **File Handling Improvements**:
  - Added multiple validation points for empty file detection
  - Implemented file size checks before processing
  - Enhanced error handling for file metadata access
  - Added safeguards in buffer finalization process

- **Build Process Updates**:
  - Removed macOS x86 build configuration
  - Streamlined build dependencies
  - Updated release artifact packaging
  - Simplified platform-specific build targets

- **Compatibility Enhancements**:
  - Added support for processing legacy buffer files
  - Improved error handling in parquet serialization
  - Enhanced file format compatibility
  - Added fallback mechanisms for file processing
