# Release 4.17.1 (November 23, 2023)

## Overview
This release reduces log verbosity in the schema evolution system by removing noisy error logging.

## Changes
- **Logging**: Reduced verbose logging in schema evolution
- **Performance**: Decreased log output volume

## Technical Details
- Disabled verbose error logging in the schema evolution system
- Removed noisy logging of failed field evolutions
- Maintained internal error handling without excessive logging
- Improved operational efficiency by reducing log output
- Error information still available for debugging when needed
