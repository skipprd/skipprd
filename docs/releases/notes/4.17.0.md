# Release 4.17.0 (November 17, 2023)

## Overview
This major release introduces significant improvements to type inference, array handling, and buffer management. It includes important changes to boolean type detection and fixes critical issues with array processing.

## Changes
- **Type System**: Improved integer and boolean type inference
- **Array Processing**: Fixed array record processing
- **Buffer Management**: Enhanced buffer pool management
- **Testing**: Added comprehensive boolean parsing tests

## Technical Details
- **Type Inference Improvements**:
  - Removed automatic inference of integers 0 and 1 as boolean values
  - Eliminated type demotion logic for boolean/integer combinations
  - Improved boolean parsing with stricter type checking
  - Added comprehensive test suite for boolean type detection
  - Removed "hacky" type inference for single-record cases

- **Array Processing Enhancements**:
  - Fixed critical bug where only first record in arrays was being processed
  - Improved handling of record types in arrays
  - Added proper sub-field handling for array elements
  - Maintained type consistency across array elements

- **Buffer Management**:
  - Implemented proactive buffer pool space management
  - Added buffer flushing before new file buffer creation
  - Improved file handle management in the buffer pool
  - Enhanced error handling for buffer operations

- **Testing Improvements**:
  - Added new test cases for boolean parsing
  - Included case insensitivity tests
  - Added validation for invalid boolean values
  - Enhanced test coverage for type inference
