# Legacy `src/catalog/*` parity checklist

This document is the authoritative mapping of legacy catalog behavior (historically implemented in `src/catalog/*`)
to the provider-based implementation under `src/react/providers/catalog/*`.

## Required behaviors (parity targets)

### Catalog build pipeline (stats → catalog write)
- **Legacy**: `src/catalog/orchestrator.rs` + `src/catalog/stats_builder.rs` + `src/catalog/catalog.rs` then `Config.write_catalog_async`.
- **Provider**: `CatalogProvider::build_all_with_progress(scope, namespaces, progress)` delegates to:
  - `react/providers/catalog/orchestrator.rs` (per-namespace orchestration)
  - `react/providers/catalog/stats_builder.rs` (stats computation)
  - `react/providers/catalog/builder.rs` (catalog construction)
  - `CatalogProvider::write_catalog(scope, namespace, catalog)` (scoped persistence)

### Semantic inference
- **Legacy**: `src/catalog/infer.rs` `infer_semantic_model_async(namespace)`.
- **Provider**: `CatalogProvider::infer_semantic(scope, namespace)` delegates to `react/providers/catalog/infer.rs`.

### Semantic persistence (“infer and write”)
- **Legacy**: `src/catalog/semantic.rs` `SemanticInfer::infer_and_write(namespace)` writes via `Config.write_semantic_async`.
- **Provider**:
  - `CatalogProvider::infer_semantic(scope, namespace)`
  - `CatalogProvider::write_semantic(scope, namespace, semantic)`

### LLM enrichment pass
- **Legacy**: `src/catalog/enrich.rs` `enrich_namespace_with_llm(namespace)` and `run_llm_enrichment_all(...)` (now dataset_id-based internally).
- **Provider**:
  - `CatalogProvider::run_llm_enrichment_all(scope, dataset_ids)`
  - uses `react/providers/catalog/enrich.rs` but with injected `llm` (no env/config creation inside providers).

### SessionFactory behavior
- **Legacy**: `src/catalog/session.rs` builds a DataFusion context and pre-registers namespace views.
- **Provider**: `react/providers/catalog/session.rs` provides the same behavior, taking `pipeline` explicitly.

### Stats computation
- **Legacy**: `src/catalog/stats_builder.rs` computes field and dataset stats for a namespace.
- **Provider**: `react/providers/catalog/stats_builder.rs` computes stats, parameterized by `pipeline`.

### Registry integration
- **Legacy**: `Config.write_catalog_async` and `Config.write_semantic_async` update `sqlrt::registry` with `catalog_key`/`semantic_key`.
- **Provider**: `CatalogProvider::{write_catalog,write_semantic}` update `sqlrt::registry` using the keys generated by `Keyspace` for the given `RequestScope`.
