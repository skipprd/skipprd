# Release Notes - Version 4.4.6

## Performance Improvements
- Implemented LRU (Least Recently Used) cache for file handling
- Optimized buffer management with configurable write buffer size
- Enhanced I/O performance with improved file handling
- Limited number of open files to prevent resource exhaustion

## File Management Enhancements
- Added LRU cache with a capacity of 100 files
- Implemented automatic flushing of least recently used files
- Improved file rotation and cleanup mechanisms
- Enhanced metadata handling for file operations

## CI/CD Updates
- Updated GitLab CI configuration for better stability
- Added support for tag-based deployments
- Enhanced runner configuration with larger machine sizes
- Improved cleanup and test procedures

## Buffer Optimization
- Introduced configurable write buffer size (512KB default)
- Added special handling for bare metal platforms (512B buffer)
- Improved buffer flushing mechanisms
- Enhanced memory usage tracking

## Technical Details
- Added new dependencies:
  - `lru` v0.10.0 for cache management
  - Updated various dependencies for better stability
- Implemented buffer configurations:
  - Standard platforms: 512KB write buffer
  - Bare metal platforms: 512B write buffer
- Enhanced file handling:
  - LRU-based file management
  - Improved file metadata tracking
  - Better error handling in file operations
- Improved logging and metrics:
  - Better status reporting
  - Enhanced error tracking
  - Improved shutdown procedures
