# Version 1.2.0

## Major Changes

### Immutable Mode Support
- Added support for immutable runs, enabling direct replication of data between formats (e.g., JSON to JSON)
- Introduced `MUTABLE_MODE` environment variable to control data transformation behavior
- Enhanced configuration handling for immutable operations

### Serialization Improvements
- Added support for format-specific default message handling
- Improved null value handling across different formats
- Enhanced type handling for various data formats

### Architecture Enhancements
- Moved default message handling from Ingest trait to individual serializers
- Improved separation of concerns in message processing
- Enhanced plugin architecture for better extensibility

## Technical Details

### Immutable Mode Implementation
- Added `$mutableMode` configuration flag to control data transformation
- Enhanced message processing to support direct data replication
- Improved handling of data types across different formats
- Added logging for immutable mode operations

### Serializer Enhancements
- Added `defaultMessage()` method to serializer interfaces:
  - SerderBatchInterface
  - SerderStreamInterface
- Implemented format-specific default message handling for:
  - Avro File
  - Avro Record
  - Avro Schema Registry
  - CSV
  - JSON
  - Parquet
  - XML
- Enhanced type handling for:
  - Arrays
  - Maps
  - Records
  - Primitive types

### Data Type Management
- Improved handling of:
  - Null values
  - Empty arrays
  - Map defaults
  - Record structures
- Enhanced type consistency across formats
- Added better support for complex data structures

### Testing Improvements
- Updated DefaultMessageTest with comprehensive type testing
- Enhanced test coverage for serializer implementations
- Added tests for immutable mode operations
- Improved test structure and organization

### Code Quality
- Enhanced error handling and logging
- Improved code organization and maintainability
- Added better type safety checks
- Enhanced documentation and comments
