# Version 4.17.30

## Changes

### File Handling Improvements
- Fixed competing access to files across threads
- Improved handling of rotated files with index pointer reset
- Enhanced buffer file management with better locking strategy
- Fixed file input plugin scanning for directory contents

### Error Handling
- Added robust error handling for file line reading
- Implemented graceful continuation on file reading errors
- Improved file rotation with better cleanup
- Enhanced buffer finalization process

### Configuration Management
- Fixed environment variable handling for chaos mode configuration
- Improved configuration priority order between env vars and YAML
- Enhanced environment variable caching
- Fixed E2E testing environment setup

## Technical Details
- Modified buffer index management in `src/buffer/mod.rs` to prevent competing file access
- Updated file finalization in `src/ingest_work.rs` to reset file pointers for rotated files
- Enhanced `src/plugins/file_input.rs` with proper error handling for file line reading
- Fixed configuration handling in `src/helpers/configuration.rs` for chaos mode settings
- Updated E2E test configuration to ensure proper environment variable precedence

## Impact
This release focuses on improving file handling and system stability, particularly in multi-threaded environments. The fixes for competing file access and proper rotation handling prevent data corruption and ensure consistent processing. Enhanced error handling for file operations prevents pipeline failures due to malformed input files. The configuration management improvements ensure consistent behavior between environment variables and configuration files, making the system more predictable across different deployment scenarios.
